# 调研：心理学、情感计算与认知架构里的"内在状态"——给灵鲸的身与意

日期：2026-10-28。目的：查清心理学、情感计算和认知架构里关于需求、情绪、动机、注意、自我、习惯的理论和计算模型，哪些能直接拿来设计灵鲸的"身"和"意"；检验"评价归模型、惯性归代码"这条分工；给出一套能用代码实现、而且便宜的内在状态模型。

## 0. 一页结论

1. **"评价归模型、惯性归代码"站得住，而且是这个领域的通行做法。** 计算情绪模型普遍拆成几个组件：评价推导（把"发生了什么"变成评价变量）→ 情绪推导（评价变量变成情绪）→ 强度 → 情绪与心情状态 → 后果（E1）。经典系统里，最难做的"评价推导"要么手写规则（ALMA、FAtiMA 的反应层），要么做符号推理（EMA、FAtiMA 的规划层）；强度、衰减、心情一律是代码公式（E1、E2、E3）〔一手〕。灵鲸用模型替掉手写的评价规则，正好补上这些系统最弱的一环〔推理〕。要修两处：模型交的应是**几项结构化评价**，最终强度、衰减、叠加、性格缩放由代码算；代码除了惯性，还要管**需求**和**调节器**（见 §4.1）。
2. **情绪和心情必须分开。** 情绪是"关于某件事"的、短的、有原因的；心情是弥散的、长的、不针对谁的。ALMA 把情感分成情绪（短）、心情（中）、性格（长）三层（E4）；FAtiMA 的心情半衰期默认是情绪的 4 倍（E3）；WASABI 里心情回落"远慢于"情绪（E6）〔一手〕。现在灵鲸的 `feel` 直接改心情，丢掉了"为什么高兴"。
3. **"随机但有性格"的心情有现成的心理学模型。** DynAffect（Kuppens 等 2010）用"围绕个人基线回弹 + 随机扰动"的随机微分方程（奥恩斯坦-乌伦贝克过程）拟合了两项日常经验取样数据；三个参数都和人格有关：基线随外向变愉快、随神经质变差；波动随神经质变大；回弹力随习惯性重评变强、随反刍变弱（D2）〔一手〕。这比"每分钟固定回落"更像人，而且免费。
4. **情绪持续多久有数据。** 27 种情绪里悲伤最长，羞耻、惊讶、恐惧、厌恶、无聊、被感动、恼火、宽慰最短，最长和最短差到约 240 倍；事件重要性和反刍（反复想）解释了将近一半的差异（D1）〔一手〕。衰减不能一个半衰期打天下。
5. **"冲动加权抽签"有先例，但缺一个"在位加成"。** ACT-R 的产生式选择、Miller 等的习惯模型都用"带噪声的 softmax"选动作（A6、H2）〔一手；H2 为一手·转写〕，这就是加权抽签。PSI 理论还多一样：**选择阈值**——正在做的事有在位优势，别的动机要高出一截才能换掉它；唤醒越高，阈值越高（S1、S2、S5）。它同时产生专注和沉迷。
6. **好奇不能等于"新鲜"。** 以预测误差为奖励的好奇会被随机噪声吸住，强化学习里叫"嘈杂电视问题"（M5）〔一手〕，正是刷信息流停不下来的计算画像。以"学习进展"为奖励的好奇会对"已经懂了"和"根本学不会"都厌倦（M3、M4）〔一手〕。
7. **沉迷可以分成"健康投入"和"成瘾样"两种。** Berridge：线索能放大"想要"，而"喜欢"不跟着涨，成瘾就是"想要"脱离"喜欢"（M6）〔一手〕；Charlton：老想着、越玩越久、玩得很爽只是高投入，冲突、戒断、复发才是成瘾的核心（M8）〔二手〕。可操作的识别规则：**想要还高、喜欢在掉、和承诺冲突**。
8. **无聊不是"闲着多久"。** MAC 模型：无聊来自注意不匹配（太简单或太难）和意义缺失；成因不同，人会去找"好玩的"或"有意思的"（M7）〔一手〕。WASABI 的无聊在没有刺激时线性上涨，并引发随机的小动作，做完小动作无聊下降（E7）〔一手〕。
9. **走神和自发回忆有清楚的规律，能免费实现。** 闲时走神多、忙时少（情境调节）；走神内容由"当前关切"即没了结的目标驱动；坏心情让思绪偏向过去和反刍，想未来能减轻坏心情（A1、A2）〔一手〕。自发回忆由与当前情境"独特重合"的线索触发，越近的事越容易冒出来，带情绪的事更容易，而且冒出来时比主动回忆更带情绪（A4）〔一手〕。ACT-R 的激活公式（新近度 + 频率 + 情境关联 + 噪声，过阈值才想起）可以直接用（A6）。
10. **会变的自我认知分三层。** 社会角色（我的特质和角色）、动机主体（我要什么、看重什么）、自传作者（我的故事）（F1）〔一手〕。更新靠"自传式推理"：从自己的经历里得出关于自己的结论；人在内心线索弱时会从自己的行为推断自己的态度（Bem，F2）〔二手〕——她的内心数值本来就弱，从行为记录推断"我最近爱看手工视频"有理论依据。
11. **习惯和人格都变得慢，而且有数。** 习惯是"情境 → 动作"的联结，靠重复长，和结果无关，被情境自动触发；日常约 43% 的行为几乎每天在同一情境里重复（H1）〔一手〕。Miller 等给了一个一行的"无价值习惯"更新公式（H2）〔一手·转写〕。日常行为达到自动化，中位数 66 天，范围 18–254 天（H3）〔二手〕。人格更慢：心理干预平均约 24 周、变化约 0.37 个标准差（P2）〔二手〕。

**推荐的内在状态模型（一句话）**：五个时间尺度叠在一起——性格（年）→ 今日状态（天）→ 需求与心情（小时）→ 情绪（分钟到天）→ 冲动（分钟到小时）；再加一层由需求和心情**算出来**的调节器（唤醒、细致度、选择阈值、查看频率），决定"怎么做"；行为用"冲动 × 成功预期 × 机会 + 习惯 + 在位加成"的带噪声 softmax 选。模型只在已有的用脑里交一份结构化评价，其余全是每分钟几毫秒的公式。详见 §4.2。

## 2. 各理论与模型的要点

只摘和灵鲸有关的主张、公式、数字。

### 2.1 PSI 理论与 MicroPsi：需求驱动、调节器、情绪是配置

PSI 是 Dörner 的"行动调节"理论，Bach 把它做成了认知架构 MicroPsi。它是和灵鲸"身 + 念 + 意"最接近的完整计算模型。

**需求（demand）与冲动（urge）**〔一手 S2；二手 S5〕
- 一切目标最终都服务于一组硬编码的需求。需求分三类：
  - 生理：食物、水、完整性（不受伤）；
  - 社会：归属（affiliation）、内在合法性（守住内化的规范，"体面"）；
  - 认知：胜任感（具体任务上的和总体的）、降低不确定、审美（进化的和抽象的）。
- 每个需求有目标值和当前值，差距就是冲动信号，"与偏离成正比"（S5）。
- 需求被满足时产生"快乐信号"，被挫败时产生"痛苦信号"；这两个信号用来强化"需求 ↔ 目标情境"的联结，并沿着记录链往回强化通向目标的步骤（S2 p.79–81）。
- 归属需求靠"合法性信号"（别人的接纳、认可）补充，"反合法性信号"（拒绝）加重；别人的求助信号同时带来挫败和满足的预期（S5）。
- 动机 = 冲动 + 一个学来的目标情境（S2 p.77）。

**动机选择**〔一手 S2 p.84；二手 S5〕
- 一个动机升为"意图"的依据：冲动的相对强度、机会、预期成功概率（"价值/风险"）、选择阈值。
- 同时可以有几个活跃动机，但只有一个主导行为；遇到机会也可能顺手满足别的需求（S5）。
- **选择阈值**调节主导动机抵抗别的动机的稳定性，取决于需求的紧迫度和个体差异（S5）。〔未核实〕Bach 2009 原书里的具体形式是给当前意图加一个在位加成，竞争者要超过"当前强度 + 阈值"才能接管；我没读到原书。

**调节器（modulator）：不管"做什么"，管"怎么做"**〔一手 S1、S2；二手 S5〕
- 四个全局调节器：唤醒（行动准备度）、选择阈值（目标稳定性）、确认频率（securing rate，多久回头检查一次环境）、分辨率（感知、回忆、规划的细致程度）（S2 p.66–67、S5）。
- 情绪不是独立模块，而是"调节器配置 + 快乐/痛苦维度 + 对胜任感和确定性的评估"（S5）。有方向的情绪（恨谁、怕什么）来自需求和某个对象的关联（S2 p.67）。
- S2 p.87–89 的例子：
  - 恐惧 = 预期厌恶事件 + 唤醒；
  - 焦虑 = 不确定 + 低胜任感 + 唤醒 + 频繁的背景检查；
  - 愤怒 = 障碍挡住了相关目标 + 惩罚障碍的倾向 + 唤醒 + 低分辨率 + 高行动准备 + 高选择阈值；
  - 悲伤 = 所有可想到的路都被堵死且没有可怪的障碍 + 寻求支持（归属需求上升）+ 低唤醒 + 抑制行动；
  - 自豪 = 高胜任感（确认频率低）+ 高内在合法性；
  - 喜悦 = 高唤醒 + 满足需求的强奖励；"至福" = 低唤醒 + 强奖励（多来自审美一类认知需求）。

**MicroPsi 2 的代码实现**〔一手 S1〕。`DoernerianEmotionalModulators` 每步计算（原文变量名）：

```
emo_activation (唤醒) = max(0, (Σ意图重要度 + Σ意图紧迫度) / (2·活跃动机数 + 1) + 冲动变化量)
base_unexpectedness  += gentle_sigmoid((意外事件数 − 预期内事件数)/10)，截断到 [0,1]
emo_securing_rate    = (1 − 当前意图的胜任感) − 0.5·紧迫度·重要度 + 恐惧(暂为0) + 意外度
emo_resolution       = 1 − emo_activation
emo_selection_threshold = emo_activation
emo_pleasure = gentle_sigmoid((预期内 − 意外)/10) + gentle_sigmoid(−3·冲动变化量)
emo_sustaining_joy：新快乐与旧值同号时取绝对值较大者，异号时直接取新值；没有新快乐时每步线性减 0.01
emo_competence = (旧胜任感 + 快乐) / (分母基线 + 符号·旧胜任感·0.1)，痛苦时分母基线为 2（掉得更快），截断到 [0.01, 0.99]
```

`emoexpression.py` 再把调节器配置读成表情：愤怒 = (1 − 胜任感) × 唤醒；悲伤 = (1 − 胜任感) × (1 − 唤醒)；惊讶 = 意外度；喜悦 = 持续喜悦 + 0.3 的基线。代码注释直说："实验性的，可能还得引入各种魔法数才能用。"

**人格 = 需求和调节器的参数**〔一手 S2 p.92–101、S3〕
- Bach 的大五映射（以需求的增益、损失、衰减表达）：
  - 神经质：负面奖励更强、胜任感和确定性掉得更多、衰减更快，容易因失去确定性而焦虑；
  - 外向：归属和胜任感的增益强、归属衰减快（更常需要补充）；
  - 开放：降低不确定的增益强；
  - 宜人：归属的正负奖励都强、胜任感增益较低；
  - 尽责/刻板：胜任感损失大、选择阈值高、需求对唤醒和分辨率的影响小。
- Dörner & Starker（S3）：Psi 的"人格"就是情绪调节的参数组，例如需求上升时唤醒上升的斜率、发现低效时胜任感下降的斜率。20 个不同人格的 Psi 和 20 名被试在"小岛"游戏里的 8 项行为指标典型相关 r = .88；和把唤醒、分辨率固定在中间值（"去掉情绪"）的同一批 Psi 相比，有情绪调节的 Psi 坏掉的次数显著更少（t = −7.96）、收集的金块显著更多（t = 14.62）。

**评价与局限**〔二手 S5〕：PSI 的自由变量很多；定量主张（记忆衰减速度、激活扩散的宽度和深度）"很少有实验证据，是工程需要的权宜之计"。例外是情绪模型，可以拟合到被试，也可以用进化模拟拟合到环境。

**LLM 时代的延续**〔一手 S4〕：Mikeda & Goertzel 把 MicroPsi/OpenPsi 改造成对话 agent 的动机层，需求换成胜任、降低不确定、归属、亲和、合法性、照料、审美。三个结构主张和灵鲸直接相关：
- **调节是"推导"不是"评价"**：调节器由需求和冲动的汇总统计算出，不靠推理；评价在调节之后、以调节器为输入（"同一句话在不同姿态下被不同地理解"）。
- **感受（feeling，行动前）和情绪（emotion，行动后）分开**：感受是需求-调节器配置的名字，用来预先配置决策；情绪是行动结果相对预期需求变化的评价，用来驱动学习。
- 六个调节器：效价、唤醒、支配感、分辨率、专注（选择阈值）、外感（向外 vs 向内注意的比例）。冲动 u_i = ω_i·φ_i(t_i − n_i)，φ 用 S 形函数，"小缺口压力弱，大缺口压力陡增"。
- 作者自认：调节器的本体没定，心情的时间尺度没定，没有实验。

### 2.2 评价理论：OCC、Lazarus、Scherer

**评价（appraisal）**：对"这件事对我意味着什么"的一组判断。评价理论认为情绪由评价的模式引起〔一手 E1〕。

**OCC 模型**〔一手 E9、E3〕
- 按"关注对象"分出 22 种情绪类型：
  - 关注**事件后果**：对自己（高兴/难过）还是对他人（替人高兴、幸灾乐祸、嫉恨、同情）；是预期中的（希望、恐惧）还是已知的；预期是否兑现（满足、恐惧成真、失望、宽慰）。
  - 关注**行为者的行为**：值得称赞还是该受责备；自己的（自豪、羞愧）还是别人的（钦佩、责备）。
  - 关注**对象的属性**：吸引（喜爱）还是排斥（厌恶）。
- 同一类型有很多"实例"，强弱不同（担心 → 恐慌）（E9）。
- OCC 是**结构模型**：只说每种情绪对应什么情境特征，"完全不说评价是怎么做出来的"（E9）。Clore & Ortony 还指出，很多情绪成分是"预先评价好的"，靠自上而下、启发式或联想的过程产生，不是每次从零评价（E9）。〔推理〕这正是 LLM 擅长的方式。
- FAtiMA 的代码实现（E3）：评价变量只有五个——合意度、对他人的合意度、值得称赞度、喜爱度、目标成功概率变化；由此推出 OCC 情绪，例如"喜爱"的强度 = |喜爱度| × 0.7（代码里叫 `magicFactor`）。

**Lazarus**〔一手 E2；Lazarus 原书未读〕：EMA 按 Lazarus 理论取的评价变量是：相关性、视角（从谁的角度）、合意度、可能性、预期性、归因（谁该负责）、可控性（自己能不能改变）、可变性（会不会被别的因素改变）（E2 §2.3）。EMA 的情绪标签表（E2 表 2）：低预期性 → 惊讶；合意且未发生 → 希望；合意且已发生 → 喜悦；不合意未发生 → 恐惧；不合意已发生 → 悲伤；不合意 + 别人造成 + 可控性低 → 愤怒；对别人不合意 + 自己造成 → 内疚。〔未核实〕Lazarus 的"核心关系主题"（愤怒 = 对我和我的人的贬低性冒犯；焦虑 = 面对不确定的威胁；悲伤 = 经历了不可挽回的失去；高兴 = 朝目标取得了合理进展……）凭已有知识，措辞待核原书。

**Scherer 成分过程模型（CPM）**〔一手 E8〕
- 评价按一串"检验"做：
  - 与我相关吗（目标相关）；
  - 后果对我的目标有利吗（目标相符）；
  - 我预料到了吗、有多确定（新奇、预期、确定性）；
  - 谁造成的、是不是我的责任（归因）；
  - 我能应对吗（应对潜力、控制、力量）；
  - 有的理论再加内在愉悦度、与自我概念和规范价值的相容性。
- 脑电研究支持新奇 → 内在愉悦 → 目标相符 → 应对潜力的**顺序**加工（Grandjean & Scherer 2008；Van Peer 等 2014；Gentsch 等 2015，经 E8 转述）。
- 情绪由五个网络构成：引发（评价）、表达、自主神经反应、行动倾向、感受（E8）。
- "相关"的定义：事件提高了满足或损害个人主要关切的概率（E8）。

### 2.3 计算情绪模型：组件框架与四个系统

**Marsella、Gratch、Petta 的组件框架**〔一手 E1〕
- 计算评价模型可以拆成：人与环境关系的表示 → **评价推导模型**（得出评价变量）→ **情绪推导模型**（评价变量 → 情绪）→ **强度模型** → 情绪/心情 → **后果模型**（对行为或认知的影响，分开环和闭环）。
- 很多系统不提供评价推导：ALMA 让开发者手写"某行为该被评价为不合意"；EMA 用领域无关的推理规则从计划结构里推出评价变量。
- 强度的四种做法：期望效用（效用 × 概率）、期望变化（事件引起的概率变化）、相加（效用 + 概率）、阈值。Gratch 等用 Battleship 棋盘游戏做被试实验，结果支持**期望效用**模型，尤其对希望和恐惧这类前瞻情绪；喜悦和悲伤这类回顾情绪可能需要改良的阈值模型。
- 维度模型（PAD 等）把核心情感表示成被事件"推来推去"、并回落到静息点的一个点；它的风险是**丢掉"关于什么"**：EM 保留了从情绪回到事件的链接，WASABI 切断了这条链接，EMA 是混合的。

**EMA**〔一手 E2〕
- 情绪 = 每个命题一个"评价框"，各带类型和强度；强度来自决策论计算（如威胁强度 = 威胁可能性 × 受威胁目标的效用）。
- 心情 = 同类评价框强度之和过 S 形函数，压到 [0,1]；心情"不针对对象、变化慢"。
- 心情反过来"渗入"评价：某个"希望"框的调整后强度 = X + 心情(希望)。
- 注意焦点 = **最近被访问、心情调整后强度最高**的那个评价框，它决定当下的情绪表现和应对。
- 应对（coping）是"评价的逆运算"：找出导致这个评价的信念、愿望、意图，去维持或改变它。
  - 注意类：主动打听、压下不想；
  - 信念类：推卸责任、一厢情愿；
  - 愿望类：疏远（降低对受威胁目标的在乎）、往好处想；
  - 意图类：做计划、求助、弥补、拖延、放弃、回避。
- 选哪种应对看可控性和可变性：可控性高 → 解决问题（行动、计划、打听）；可变性高 → 拖延等变化；两者都低 → 情绪应对（疏远、往好处想、放弃）。
- 一句关键观察："形成一个意图本身就能改善情绪状态，哪怕从没执行。"

**FAtiMA**（开源，C#）〔一手 E3、E10〕。代码默认值：
- 情绪强度 = 潜能 − 阈值，截断到 [0,10]；强度 ≤ 0.1 就移除。
- 每种情绪类型有一个"情绪倾向"：阈值和衰减率（0–10）。这就是 FAtiMA 的人格参数。
- 衰减：I(t) = I₀·exp(λ·衰减率·Δt)，λ = ln(0.5)/情绪半衰期，**情绪半衰期默认 15 个时钟周期**。
- 叠加：同一原因（或同一属性变化）的情绪视为重新评价，替换旧的，且不重复改心情；不同原因各自成一条。代码另有一个"加强"方法，用 ln(e^旧潜能 + e^新潜能)，是递减收益的软最大值。
- 心情：一个 [−10, 10] 的数；新情绪按效价 × 强度 × **0.3** 推心情；**心情半衰期默认 60 个周期**；|心情| < 0.5 视为中性、不影响情绪。
- 心情影响新情绪：潜能 += 效价 × 心情 × **0.3**。
- 希望和恐惧（未定的前景）不影响心情，其余都影响。
- 每个情绪都记着原因事件号和对象。
- 后来的 FAtiMA Modular 加了情绪性事件的自传体记忆，以及**取自 Dörner PSI 的基本动机模块**，从中派生具体目标（E10）〔一手〕。也就是说，"需求驱动 + OCC 评价"的组合已有先例。

**ALMA**〔一手 E4；系数 二手 E5〕
- 情感按时间分三类：情绪（短、强、具体）、心情（中、不被注意、弥散）、性格（长）。引 Davidson："情绪偏置行动，心情偏置认知"。
- 用 OCC 的 24 种情绪；大五人格调节情绪强度和衰减。
- 心情是 PAD 空间里的一个点：P = 愉悦，A = 唤醒，D = 支配感，各在 [−1,1]；八个卦限对应八种心情——兴高采烈 (+P+A+D)、无聊 (−P−A−D)、依赖 (+P+A−D)、轻蔑 (−P−A+D)、放松 (+P−A+D)、焦虑 (−P+A−D)、温顺 (+P−A−D)、敌意 (−P+A+D)；心情强度 = 到原点的距离。
- **默认心情由大五决定**：情绪稳定性 → 愉悦 +、唤醒 −；宜人性 → 愉悦 +、唤醒 +、支配 −；外向和尽责 → 愉悦 +、支配 +；开放 → 三者都 +（E4 第 13 页）。Mehrabian 1996 的系数经 E5 转引为：P = 0.21E + 0.59A + 0.19S；A = 0.30A − 0.57S + 0.15O；D = 0.60E − 0.32A + 0.25O + 0.17C。E5 把第三个变量写成"神经质 N"，但从符号看应是"情绪稳定性 S"，和 ALMA 幻灯片一致〔未核实，需核 Mehrabian 原文〕。
- 心情变化分两步：**拉**（当前情绪把心情拉向它们的 PAD 重心）和**推**（心情已经在那个方向时，同向情绪把它推得更远、更强）。E5 转述的形式：心情在原点与重心之间时靠近重心，越过重心后同向情绪让它继续远离原点〔二手〕。

**WASABI**〔一手 E6、E7〕
- 情绪效价 x 和心情效价 y 各挂一根"螺旋弹簧"拉回原点；弹簧系数和"惯性质量"是人格参数。作者说选质量-弹簧是因为它"比线性和指数衰减更像情绪的时间进程"——这是启发式判断（E7）。
- 情绪影响心情：Δy = a·x·Δt，a 小 = 迟钝，a 大 = 情绪化（E7）。
- **无聊轴** z ∈ [−1, 0]：当 (x, y) 落在原点附近的小邻域（没刺激）时线性下降，速率 b 是人格参数；离开邻域就复位（E7）。
- 映射到 PAD：愉悦 = x 与 y 的标准化和；唤醒 = |x| + z（任何情绪都带唤醒，无聊降低唤醒）；支配感来自认知层对局面的判断（E7）。
- 无聊明显时随机执行"替代活动"（打哈欠、伸懒腰、东张西望），做了就降低无聊；作者说无聊轴"让主动行为自然地冒出来"（E7）。
- 输入是效价脉冲，来源三种：理解模块（"用户这句是夸奖"→ 正）、对话管理（达成对话目标 → 正）、感知（每次看到用户 → 正）（E7）。
- 心情是单一的好坏维度，"远慢于"情绪回落；心情让情绪的引发**与心情一致**——心情好时更不容易出现负面情绪（引 Neumann 等）（E6）。
- 初级情绪（9 种，含无聊、专注）按 PAD 距离直接出现；次级情绪（希望、恐惧成真、宽慰）必须由认知触发，寿命默认 10、线性衰减（E6）。

**其他系统**〔一手 E10〕
- MAMID：情绪通过三条路影响处理——分配处理资源（决定什么被处理）、直接影响目标和动作选择、改变各模块的速度和容量（模拟神经调质）。
- Rank 扩展的 JAM agent：评价超过强度阈值时同时产生三件事——一个"表达冲动"目标、一个应对目标（可能变成意图）、对相关者评价的改变。
- 〔推理〕后者几乎就是灵鲸的 `feel` / `want` / 关系印象更新三件套。

### 2.4 情绪与心情的时间动力学

**情绪有多长**〔一手 D1〕
- 被试回忆近期情绪事件，报告持续时间、评价和调节策略，覆盖 27 种情绪。
- 中位数：以"第一次回到基线"为终点约 2 小时，以"彻底恢复"为终点约 5 小时。
- **悲伤最长**；羞耻、惊讶、恐惧、厌恶、无聊、被感动、恼火、宽慰最短；最长约为最短（羞耻）的 240 倍。
- 内疚远长于羞耻；焦虑远长于恐惧；无聊虽然"度日如年"，单次却很短。
- **事件重要性**（与持续时间相关 .59/.57）和**反刍**两项解释了情绪间差异的将近一半；控制了新近度和强度后结论不变。
- 机制：重要事件的含义会随时间逐步显现，维持或加强情绪；持续把注意放在引发事件上会延长情绪，对正面情绪同样成立（反复想一件好事会延长喜悦）。

**心情怎么起伏：DynAffect**〔一手 D2〕
- 每人有一个**情感基线**（home base），情感围绕它波动；波动来自内外各种因素；**回弹力**（attractor strength）把它拉回基线。三者都有稳定的个体差异，效价和唤醒各一套。
- 方程（单维；PDF 抽取丢了希腊字母，符号为本文所设）：观测 Y(t) = θ(t) + ε(t)；变化 dθ(t)/dt = β·(μ − θ(t)) + ξ(t)。μ 是基线，β 是回弹力，ξ 是随机扰动。原文的说法是"瞬时变化 = 基线与当前位置的有向距离 × 回弹力 + 随机扰动"，这是奥恩斯坦-乌伦贝克过程。
- 与人格的相关：外向、自尊、生活满意度 → 基线更愉快；神经质 → 基线更不愉快、唤醒基线更高、效价波动更大；习惯性重评 → 唤醒回弹力更强；习惯性反刍 → 唤醒回弹力更弱。
- 模型拟合优于没有个体差异或没有吸引子的对手模型；用个人参数模拟出的轨迹和真实数据很像。

**情绪惯性是警讯**〔二手 D3〕：情绪"抗拒改变"的程度（自相关）高，正负情绪都一样，和低自尊、抑郁相关；后续研究里，青少年的高情绪惯性预测了 2.5 年后的临床抑郁。〔推理〕心情回落太慢的数字生命会显得"郁"。

**Frijda 的情绪定律**〔未核实 D4〕：习惯化律（持续的愉快条件，愉快会消退）、享乐不对称律（快乐依赖变化、会在持续满足中消失，痛苦在持续的不利条件下可以一直存在）、比较感受律（情绪强度取决于和参照框架的差距）。原文未读。

### 2.5 动机与内在动机："想做什么"从哪来

**自我决定理论（SDT）**〔一手 M1〕
- 三种天生的心理需求：**胜任、自主、关系**。满足时自我驱动和心理健康提升，受挫时动机和幸福感下降。
- 认知评价理论（CET）是 SDT 的分支：
  - 带来胜任感的反馈能提升内在动机，但**只在伴随自主感时**才有效；
  - 预期内、按表现给的有形奖励会可靠地削弱内在动机（Deci、Koestner、Ryan 1999 的元分析）；
  - 威胁、截止时间、指令、施压的评价、强加的目标也会削弱；选择、承认感受、自我主导的机会会增强。
- 关系：婴儿安全依恋时探索更多；冷漠、不回应的大人在场时，孩子的内在动机很低。

**Panksepp 的七个基本情绪系统**〔一手 M2〕
- 用脑内电刺激（ESB）能在皮层下诱发七类原始情绪反应：寻求（SEEKING）、愤怒（RAGE）、恐惧（FEAR）、性欲（LUST）、照料（CARE）、惊恐/悲伤（PANIC/GRIEF，分离痛苦）、玩耍（PLAY）。
- 这些回路位于所有被测脊椎动物的同源皮层下区域，去掉新皮层后仍在；刺激它们本身就能当奖励或惩罚。
- M2 的参考文献里，Panksepp 把抑郁解释为"分离痛苦（PANIC）加上寻求系统（SEEKING）减弱"〔二手，只见标题〕。

**内在动机的计算类型学**〔一手 M3〕。Oudeyer & Kaplan 把计算模型分三族：
- **知识型**：奖励来自对世界的预测或信息。
  - 不确定性动机：奖励 ∝ 1 − P(事件)；
  - 信息增益；
  - 预测新奇：奖励 ∝ 预测误差；
  - 中等新奇：误差接近某个最佳值时奖励最大，需要手调阈值；
  - **学习进展**：奖励 = 预测误差的下降。
- **能力型**：奖励来自达成自己设定的挑战。
  - 最大化无能：偏爱做不到的；
  - **能力进展**：偏爱"开始不会、很快变会"的挑战。作者说这就是心流的计算版本，而用两个阈值框定"难度刚好"的做法脆弱、要手调。
- **形态型**：只看感觉运动流的数学性质，如同步性。
- 结论：学习进展、能力进展、信息增益这类"自适应、非稳态"的动机同时有高探索性和高组织性，会主动避开太容易和太难的事。Playground 实验里，学习进展驱动的机器人自发出现了"乱动 → 玩身体部位 → 对物体尝试各种动作 → 发现可供性"的发展阶段。
- 心理学源头：Berlyne 的"中等新奇最有回报"、Hunt 的"最佳不一致"、White 的效能动机、Csikszentmihalyi 的心流（M3 综述）。
- 驱力理论被批评：探索不是稳态的，不是对身体扰动的消费性反应（White 1959，经 M3）。

**Schmidhuber：乐趣 = 压缩进展**〔一手 M4〕
- 内在奖励 = 世界模型（压缩器）的改进量，即可预测性的一阶导数。
- "婴儿很快会对已经很懂的东西厌倦，也会对完全不懂的东西厌倦，总在找那些还没解释、但容易学会的规律。"
- 白噪声信息量最大，却"不惊奇而是无聊"，因为它不允许进一步压缩；黑屋子会变得可预测，于是也无聊，奖励最大化的 agent 会离开去找新的可学规律。

**嘈杂电视问题**〔一手 M5〕
- 以预测误差为好奇奖励时，如果环境里有随机转移，agent 会去追熵最高的转移。
- 实验里在迷宫中放一台按动作随机换台的电视，学习被"大幅拖慢"。
- 模型能力不足、部分可观测带来的"不可预测"也会造成同样的问题。

### 2.6 无聊、心流、沉迷与成瘾

**无聊的 MAC 模型**〔一手 M7〕
- 无聊是"在有价值的目标相符活动中，注意投入失败"的情感信号，来自两种缺失：
  - **注意**：认知需求和可用心理资源不匹配，包括刺激不足和刺激过度；
  - **意义**：活动和看重的目标不符，或根本没有看重的目标。
- 两者各自独立地产生无聊，组合出不同的无聊（表 2）：
  - 低意义 + 低投入（低需求低资源）→ 去找**好玩的**；
  - 低意义 + 高投入 → 去找**有意思的**；
  - 高意义 + 刺激不足 → 提高难度；
  - 高意义 + 刺激过度 → 补充资源。
- 四种缓解办法：换活动（对"无意义的无聊"最有效）、调整目标价值（重新理解这件事的意义）、调整难度、调整资源（如睡一觉）。
- 无聊有多难受：反复看同一段 85 秒的网球视频一小时，被试平均电击自己 22 次，93% 至少电了一次（Havermans 等 2015，经 M7 转引）。

**WASABI 的无聊**〔一手 E7〕：没有刺激时线性上涨，引发随机的小动作，做了就下降（见 §2.3）。

**无聊很短**〔一手 D1〕：无聊是 27 种情绪里最短的一组之一。〔推理〕无聊应该很快推动换事，而不是攒几个小时。

**心流**〔二手 M9〕：挑战与技能平衡时出现；技能大于挑战 → 无聊，挑战大于技能 → 焦虑；伴随目标清晰、即时反馈、行动与意识融合、时间感扭曲、活动本身就是回报。能力进展是它的计算版本（M3）。

**"想要"与"喜欢"**〔一手 M6〕
- 激励显著性意义上的"想要"由大范围的中脑-边缘多巴胺系统产生；真正的享乐冲击即"喜欢"依赖小得多的系统，不靠多巴胺。
- "想要"常由**和奖励有关的线索或生动想象**以脉冲方式触发，和认知目标联系弱，让线索抓注意、诱人；冲动强度 = 线索的奖励关联 × 个体当前的大脑状态。
- 成瘾的本质：在易感的人身上，"想要"被长期放大，尤其由线索触发，"喜欢"不一定跟着放大。
- 这一理论正被扩展到赌博、网络、"过度爱好"等行为成瘾（作者语气谨慎）。

**成瘾 vs 高投入**〔二手 M8〕：442 名网游玩家的因素分析得到两个因素。
- 成瘾因素：冲突、戒断、复发与恢复、行为显著性（这件事主宰行为）；
- 非病理的投入因素：认知显著性（老想着）、耐受（越玩越多）、欣快。
- 玩家通常先满足投入标准，再满足成瘾标准。

### 2.7 注意、走神与自发回忆

**走神的规律**〔一手 A1〕
- 走神 = 注意从当前任务转向自生的想法和感受，依赖"感知脱耦"（屏蔽外界约束）。
- **情境调节假说**：任务不费神时走神更多；认知控制好的人在任务要求高时少走神、要求低时多走神。飞行员在航段顺利时更常走神，当副驾驶时走神几乎翻倍（Casner & Schooler 2013，经 A1）。
- 内容：大部分走神和个人及亲近之人的关切有关，常指向现在以外的时间，有**未来偏向**；工作记忆负荷会削弱这种偏向。
- 情绪：
  - 走神时心情普遍偏低（Killingsworth & Gilbert 2010）；
  - 坏心情让走神偏向过去（Smallwood & O'Connor 2011），并引发更多走神（Smallwood 等 2009）；
  - 想未来能减轻随后的负面情绪（Ruby 2013），并降低社会压力后的皮质醇；
  - 反刍过去和负面心情相关，而且常常没被觉察，所以难以脱身。
- 好处：走神有助于创造性的"酝酿"（Baird 等 2012）、自传式计划、延迟满足；职业作家和物理学家约 1/3 的创意出现在做与工作无关的事、想着别的事的时候，这类创意更常伴随"啊哈"体验、帮人突破僵局（Gable 等，经 A1）。

**当前关切理论**〔一手 A2〕。Klinger 的五条原则：
1. 对某个目标的投入，使人对和目标有关的线索（外部的或自己脑子里的）更敏感：更容易注意到、记住、想到、梦到、行动；
2. 这些反应伴随（甚至先于）原情绪或完整的情绪唤醒，唤醒幅度决定反应概率，和目标价值有关；
3. 情境有利于推进目标时，反应表现为推进目标的行动或心理操作；
4. 情境不利时，反应停留在心里，比如走神和做梦，但内容仍反映这个目标；
5. 走神在心里没事时更可能，当前任务利害越大越不可能；放松时和睡眠中最可能。

A2 里的数字：
- 双耳分听实验中，被试回忆起与自己目标相关段落的次数约是无关段落的 **2 倍**，想法内容与之相关的次数也约 2 倍（Klinger 1978）；
- 睡眠中播放刺激，梦的内容和"自己目标相关刺激"吻合的次数约是"他人目标相关刺激"的 **3 倍**；
- 一项自发思维研究里，想法的个人重要性均分 5.26/7，19% 指向过去、28% 指向未来（Andrews-Hanna 等 2010，经 A2）。

**走神本身不坏，内容才是关键**〔一手 A2 对 A3 的再分析；A3 二手〕
- Killingsworth & Gilbert：2,250 名用户被随机提示，46.9% 的时间在走神；除了亲密行为外，任何活动中走神都至少占 30%；走神解释了 10.8% 的个人内幸福感差异，而活动本身只解释 4.6%；时滞分析提示走神在前、不快在后〔二手〕。
- Klinger 的再分析：42.5% 的走神是关于愉快的事，此时心情约等于不走神；31% 是中性的，心情略低于平均但高于中点；只有 26.5% 关于不愉快的事，此时心情明显低于平均和中点〔一手 A2〕。

**自发的自传体回忆**〔一手 A4；比例二手 A5〕
- 定义：没有先前提取意图、自己冒出来的个人往事。
- 频率：日常里很常见。被试用机械计数器记 24 小时，自发回忆的次数是主动回忆的两倍多（A4 原话；A5 的摘要据检索称"三倍"，未核原文）。绝对频率很难估，记录要求越繁琐，报的越少。
- 触发：绝大多数有可识别的线索，即当前情境与记忆内容的特征重合；外部线索（物体、地点、人、感官印象、活动）比内部线索（想法）更常见。线索要足够"独特"才能触发：和很多往事共享的特征是差线索；只去过一次卢浮宫，再去时就会想起第一次。
- 时间：离事件越久越少冒出来，近期事件占主导，接近经典遗忘曲线。
- 情绪：带情绪的、新奇的事更容易被想起，延迟后尤其明显；自发回忆比主动回忆**更快**，并且**情绪冲击更强**。
- 与走神的区别：自发回忆是快速、联想式、几乎不需要执行控制的"类型 1"过程；走神需要感知脱耦，靠执行控制调节，更像"类型 2"。一段自发回忆可能引出一段走神。

**ACT-R 的记忆激活：为什么"此刻"想起这件事**〔一手 A6〕

```
A_i = B_i + Σ_j W_j·S_ji                      激活 = 基础激活 + 来自当前情境元素的关联激活
B_i = ln( Σ_{k=1..n} t_k^(−d) )               t_k 是第 k 次接触以来的时间；d 默认 0.5
P(提取 i) = e^(A_i/s) / ( e^(τ/s) + Σ_k e^(A_k/s) )   s ≈ 0.25 是噪声，τ 是提取阈值
T_i = F·e^(−A_i)                               提取时间
产生式（动作）选择：P(i) = e^(U_i/t) / Σ_j e^(U_j/t)，效用噪声 t ≈ 0.5
```

- 基础激活来自 Anderson & Schooler 1991 的理性分析：它追踪"一件事再次被需要"的对数几率。每次接触的影响按幂函数衰减，产生遗忘的幂律；多次接触相加，产生练习的幂律。
- 动作选择是带噪声的 softmax：效用高的更常被选，但不总被选。

**做计划能平息心事**〔二手 A7〕：未完成的目标会在无关任务中引发侵入性想法，提高相关词的可及性，并拖累其他任务；为它做一个具体计划就能消除这些效应。真正执行了计划的人效果更好。

### 2.8 自我与叙事

**自我的三层**〔一手 F1〕。McAdams："自我是'我'（I）遇见'我的样子'（Me）时发生的事。"
- **社会演员**：约 18 个月起出现。主要"货币"是特质和角色：特质是"我认为自己在各种社交场合的一贯风格"，部分来自"我认为别人怎么看我"；角色是重要关系的结构。两者构成"我心中的社会声誉"。
- **动机主体**：5–7 岁起，在演员之上叠加目标、价值、计划、项目。
- **自传作者**：青春期和成年早期出现。**叙事身份**是"一个内化的、不断演变的自我故事，重建过去、想象未来，给人生一定的统一、意义和目的"。
- **自传式推理**：从分析自己的经历中得出关于自己的实质性结论，把事件串成因果链，归纳出人生主题。
- 故事在讲述中成形：讲给别人听、看反馈、据此修改、获得新经历再讲……"自我创造故事，故事再创造新的自我"（McLean 等 2007，经 F1）。
- 救赎型叙事（从苦难走向更好）在美国成年人里和心理健康、公民参与相关，但 McAdams 也指出它带有文化偏见，并非放之四海皆准。

**从行为推断自己**〔二手 F2〕：Bem 的自我知觉理论认为，人像旁观者一样从自己的行为推断自己的态度，尤其在内心线索弱、模糊的时候。

**自我-记忆系统**〔二手 F3〕：自传体记忆是"工作自我"的当前目标和"自传知识库"共同建构的暂时产物；工作自我通过塑造提取线索控制能想起什么，知识库反过来"锚定"工作自我的目标。〔未核实〕原文的三层知识（人生时期、一般事件、具体事件细节）凭已有知识。

**可能自我**〔未核实 F4〕：Markus & Nurius 1986，人对"可能成为的自己"的表征，包括希望的自己和害怕的自己，它们引导动机。

**自我模型理论**〔二手 F5〕：Metzinger 认为不存在"自我"这个东西，只有在意识经验中出现的现象自我；它是一个"透明的自我模型"的内容，即系统体验不到这个模型是模型。〔推理〕能落地的只有一点：注入给模型的自我认知要用第一人称、作为"她自己的感觉"出现；对主人则必须是可查看、可追溯的数据。

**LLM 架构里的自我模型**〔一手 S4〕：Mikeda & Goertzel 要求同时维护世界模型、自我模型、用户模型。"没有自我模型的系统认不出自己的行为漂移。"

### 2.9 习惯

**习惯是什么、怎么长**〔一手 H1〕
- 习惯是"在反复出现的情境里重复行为的倾向"，是习得的自动反应。两个定义特征：
  - 由**反复出现的情境线索**激活；
  - **对目标的短期变化不敏感**，包括结果价值和行为-结果关联的变化。
  - 其他常见特征：快、省力、少思考、刻板、整串执行。
- 经验取样研究：每小时记录一次，约 **43%** 的行为几乎每天发生，而且通常在同一情境（Wood 等 2002）。参与者常说做这些事时没在想。
- 学习机制：
  - 每次重复，赫布式学习都逐步加强情境线索与反应的联结（"直接提示"）；
  - 奖励调节联结强度：多巴胺预测误差在最初重复时活跃，随着奖励重复出现而减弱；
  - 和奖励关联的情境线索会让习惯动作更有劲。
- 结果不敏感的证据：
  - 习惯强的人在电影院照样吃难吃的陈爆米花，换到会议室就按喜好少吃（Neal 等 2011）；
  - 过度训练后，即使已吃饱、不想要那个奖励，人仍然做出习惯选择（Tricomi 等 2009）。
- 64 项研究的元分析：偶尔做的事更由意图预测，经常重复的事更由过去频率（习惯）预测（Ouellette & Wood 1998）。
- 间隔强化程序（隔一段时间才有奖励）最容易养成习惯。
- 打破习惯：搬家、换工作这类**生活转变**减少了旧线索，是按新意图行事的窗口；改变情境线索也能削弱旧习惯。
- 形成新习惯的三根支柱：稳定情境中的重复、合适的奖励安排、频繁执行。

**习惯形成要多久**〔二手 H3；H1 转引〕
- Lally 等：96 人每天重复一个健康行为 84 天。39 人的自动化曲线拟合良好，达到渐近线 95% 的中位数是 **66 天**，范围 18–254 天（254 天是外推）。
- 去健身房每周 4 次，约 6 周变自动（Kaushal & Rhodes 2015，经 H1）。
- 评述文章提醒：66 天基于小样本，尚未重复验证。

**无价值的习惯模型**〔一手·转写 H2〕

```
习惯：H_{t+1} = H_t + α_H·(a_t − H_t)       a_t 是本次所选动作的独热向量；只看选过什么，不看结果
目标导向：R_{t+1}(a,m) = R_t(a,m) + α_R·(r_t(m) − R_t(a,m))；Q(a) = Σ_m U(m)·R(a,m)
仲裁：D(a) = w·θ_h·H(a) + (1 − w)·θ_g·Q(a)；选择 π(a) = softmax(D(a))
w = 1 / (1 + e^(w_g·g − w_h·h + w_0))       g = 行为-结果关联强度，h = 习惯化程度
```

模型复现了：重复本身让人偏向最近选过的动作（坚持）、过度训练后对结果贬值不敏感、对取消关联不敏感、间隔程序比比率程序更快形成习惯、两类脑区损伤的不同表现。

### 2.10 人格的稳定与变化

- **特质 = 状态的分布**〔二手 P1〕：Fleeson 2001 用 2–3 周的经验取样测大五相关的状态。每个人几周内会表现出各特质的大部分水平；个体之间分布的中心几乎完全稳定，**变异度本身**也是稳定的个体差异。
- **稳定性随年龄上升**〔二手 P3〕：7 年间隔的等级稳定性系数，从童年约 .3 升到成年早期约 .6，再到成年后期约 .7；Bleidorn 等 2022 认为在成年早期就进入平台。
- **干预能改人格，但慢**〔二手 P2〕：207 项研究，干预平均约 24 周，人格测量变化约 d = .37；情绪稳定性变化最大，其次是外向；效果在随访中保持。
- **短期过程怎么积成长期变化**〔二手 P4〕：TESSERA 框架认为长期人格发展来自反复的短期情境序列——触发情境 → 预期 → 状态及其表达 → 反应。反思过程（如比较）主要改变外显的自我概念，联想过程（如强化学习）主要改变内隐的；可用于行为特质、动机取向和人生叙事。实证支持目前只是部分的。

### 2.11 依恋与关系

**依恋控制系统**〔一手 R1、R2〕
- Bowlby 把依恋看作一个"依恋控制系统"，维持依恋行为和探索之间的**平衡**；危险线索会暂时把平衡推向依恋。
- 个体差异体现为能否把照料者当作**安全基地**；平衡状态反映照料者过去回应的敏感度和有效性。
- 陌生情境实验里，最能反映家庭环境的不是分离时哭不哭，而是**重聚时**能否顺畅回到平静和探索（而不是生气或回避）（R1）。
- 计算模型多以"保持与照料者的接近"为设定目标（R2）。
- 依恋可在一生中、任何两人之间形成（R2）。

**分享好消息**〔二手 R3〕
- 把好事告诉别人（capitalization）当天的正面情绪和生活满意度更高，超出好事本身带来的部分。
- 对方的回应分四种：主动建设（热情、追问、一起高兴）、被动建设、主动破坏、被动破坏。只有主动建设的回应和更高的承诺、信任、满意、亲密相关。

**情绪的社会分享**〔一手 R4〕
- 情绪事件之后，80%–95% 的情况下当事人会和别人谈起；跨文化、跨教育程度都如此。
- 恐惧、愤怒、悲伤和喜悦、爱一样常被分享；羞耻和内疚分享得少一些。
- 越强烈的事件被分享得越多次、持续越久；分享会逐渐消退。
- 宣泄说不成立：相关研究和实验都显示，分享本身不会减轻这段记忆的情绪负荷。但分享者觉得有益——认知上"理清了"，社交上得到安慰。
- 作者解释：情绪刚发生时（正是分享最多的时候），人还不愿放下受挫的目标、不愿重新理解局面；情绪恢复需要这种认知加工，写作类方法更可能促进恢复（Pennebaker，经 R4）。

**关系动力学**〔二手 R5〕：Gottman 等用差分方程描述夫妻对话中两人情绪的相互影响，核心概念有惯性、不受影响时的稳态、影响函数、受影响后的稳态（吸引子）。〔未核实〕形式大致是 W_{t+1} = a + r₁·W_t + I(H_t)，凭已有知识。

### 2.12 节律

**两过程模型**〔一手·转写 T1〕
- 睡眠压力（过程 S）醒着时按饱和指数上升，睡眠中随慢波活动指数下降；昼夜节律（过程 C）用正弦表示，相位来自警觉度数据。
- S 在两个阈值之间摆动；上阈值受偏斜的正弦调制；剥夺睡眠时上阈值升高，卧床、温暖、黑暗、缺少社交刺激时降低。
- 这篇综述没给时间常数。〔未核实〕常被引用的值是醒时上升约 18 小时、睡时下降约 4 小时（Daan、Beersma、Borbély 1984）。

**日内心情**〔二手 T2〕
- Golder & Macy 分析了 84 国 240 万用户两年的 5.09 亿条推文（用 LIWC 词典打分，是心情的代理指标）。
- 正面情绪每天两个峰：清晨和接近午夜；人醒来时心情好，白天逐渐变差，作者联系到睡眠和昼夜节律。
- 周末更快乐，早晨的峰推迟约 2 小时；正面情绪基线随日照长度的变化而变化。

## 4. 对灵鲸的产出

### 4.1 产出 1：对"评价归模型、惯性归代码"的检验

**结论：站得住，而且和计算情绪模型多年来的通行拆法一致；但要从"二分"细化成"四分"：① 模型做评价（这件事对我意味着什么）；② 代码做情感动力学（强度、衰减、叠加、心情）；③ 代码做动机动力学（需求、调节器、冲动、选择、习惯）；④ 慢想按需做应对和冲突裁决（也用模型，但不是每次）。**

**各系统里，评价和状态更新是怎么分的**

| 系统 | 评价推导（这件事对我意味着什么） | 情绪推导与强度 | 状态更新（衰减、心情、叠加） | 对行为的影响 | 依据 |
| --- | --- | --- | --- | --- | --- |
| PSI / MicroPsi | 没有 OCC 式的显式评价；事件直接改变需求、确定性、胜任感 | 情绪不是变量，是调节器配置的读数 | 全部是每步公式 | 调节器改变"怎么做"；冲动强度和成功预期决定"做什么" | 一手 S1、S2 |
| EMA | 领域无关的推理规则从计划结构推出评价变量，作者称"本质上是模式匹配，很快" | 规则得标签；强度 = 可能性 × 效用 | 心情 = 同类评价之和过 S 形函数；心情渗入评价 | 应对策略改变信念、愿望、意图 | 一手 E2 |
| FAtiMA | 作者手写的评价规则（事件模式 → 合意度等） | OCC 推导代码；强度 = 潜能 − 阈值 | 指数衰减、同因替换（另有软最大值式加强）、心情 ±10、心情偏置 0.3 | 情绪进入决策模块 | 一手 E3、E10 |
| ALMA | 由开发者给对话行为和情感行为标注 OCC 变量 | OCC 引擎，大五调节强度和衰减 | PAD 心情的拉和推，默认心情由大五决定 | 情绪和心情都可影响行为 | 一手 E4、E1 |
| WASABI | 认知层发出效价脉冲（夸奖 → 正；达成对话目标 → 正；看到用户 → 正）；次级情绪由认知触发 | 按 PAD 距离得"觉察可能性" | 弹簧加质量、心情慢回、无聊轴 | 表情、语速、呼吸；情绪写成信念，影响计划选择 | 一手 E6、E7 |
| Mikeda & Goertzel | 评价以调节器为输入，"同一句话在不同姿态下被不同理解" | 感受 = 配置的名字（行动前）；情绪 = 结果评价（行动后） | 调节器由需求汇总推导，"不靠推理" | 快慢两路按紧迫度和唤醒连续混合 | 一手 S4 |

共同点〔一手 E1；推理〕：
1. 把"这件事意味着什么"交给领域知识（规则、规划器、开发者标注）；
2. 把"有多强、持续多久、怎么叠、心情怎么变"交给公式；
3. 把"情绪怎么改变行为"交给一组全局参数或策略。

灵鲸让 LLM 做第一件事，等于用一个通用的领域知识库替掉了这些系统里最费人工、最难泛化的部分。这是这次调研对现有分工最重要的支持。

**需要修的四处**〔推理，依据见各条〕
1. **模型交"结构化评价"，不交最终强度。** 理由：
   - 强度怎么算是一个可以独立验证的组件，期望效用模型有实验支持（E1）；
   - 性格对强度的缩放应该稳定、可调（FAtiMA 的阈值和衰减率、ALMA 的大五调节）；
   - 模型给的数字往往挤在 0.6–0.8，不同性格会被拉平〔推理，待实测〕。
   - 建议 `feel` 交：效价、重要度、类型（一个小的 OCC 式标签集）、原因和对象、可选的预期性与可控性；最终强度由代码按性格算。
2. **代码不只是惯性。** PSI 和 Mikeda & Goertzel 都把"需求缺口的累积"和"调节器的推导"放在代码里，而且明确说调节"是推导不是评价"（S1、S4）。灵鲸的身要多管两样：需求（联结、认可、新知、胜任、自主）和调节器（唤醒、细致度、选择阈值、查看频率）。
3. **心情对评价的反馈只做一处。** EMA、FAtiMA、WASABI 都让心情偏置新情绪（E2、E3、E6）。灵鲸的模型在提示里已经看到心情；代码如果再加一道心情偏置，就会重复计算，容易形成负面螺旋〔推理〕。建议：模型看心情只用于语气和理解；代码里的心情偏置系数设小（例如 FAtiMA 的 0.3 再减半），并实测。
4. **保留"关于什么"。** 维度模型容易丢掉情绪的原因（E1：WASABI 切断了链接，EM 保留了）。灵鲸的情绪事件要带原因事件号和对象，心情只是汇总；这样她能说出"我有点难过，因为……"，也能被回忆重新激活（D1：反刍延长情绪）。

**我们四个机制的理论先例**

| 灵鲸的机制 | 先例 | 和先例的差别 | 建议 |
| --- | --- | --- | --- |
| 冲动加权抽签 | ACT-R 产生式选择：P ∝ e^(U/t)，t ≈ 0.5（一手 A6）；Miller 等的仲裁 softmax（一手·转写 H2） | PSI 的动机选择不是抽签，是"最大者胜 + 在位加成"（S2、S5） | 保留 softmax，加上在位加成（选择阈值）防止来回摇摆，并让唤醒高时更难切换 |
| 门槛噪声 | ACT-R：激活加噪声 s ≈ 0.25，超过阈值 τ 的概率是 logistic 函数（一手 A6）；DynAffect 的随机扰动项（一手 D2） | 灵鲸只说"门槛带噪声"，给的例子是心跳间隔在 20–45 分钟里均匀抽 | 改成"过线概率"：P(过线) = 1/(1 + e^(−(强度 − 门槛)/s))，s 由性格定；比均匀抽间隔更有依据 |

| 性格数值化 | ALMA（大五 → 默认心情、情绪强度和衰减）、FAtiMA（每类情绪的阈值和衰减率）、PSI（大五 → 需求增益、损失、衰减和选择阈值）、WASABI（弹簧系数、质量、a、b）、DynAffect（基线、波动、回弹力与人格相关） | 灵鲸的六维是自拟的，缺宜人性；"敏感度"和"情绪稳定性"都和神经质有关、边界不清 | 对齐大五（§4.2.4）：敏感度 = 反应增益，情绪稳定性 = 回弹力；建议加"温和"（宜人性），用于关系修复和被批评时的反应 |

### 4.2 产出 2：推荐的内在状态模型（身 + 意）

全部是本体里的数值和每分钟一次的函数；模型只在已有的用脑里顺手交一份评价。下面每处都标依据；数值默认值都是〔推理，待实测〕，给的是"怎么定"的锚点，而不是拍定的数。

#### 4.2.1 总图：五个时间尺度加一层调节器

```
性格（年）  六+一个维度 ─┬─> 各种基线、增益、半衰期、温度（§4.2.4）
                        │
今日状态（天） AR(1) 跨天相关的偏移 ─┤
                        ▼
需求（小时~天）  精力 · 联结[每人] · 认可 · 新知 · 胜任 · 自主 · 无聊
心情（小时）     效价 V、唤醒 A：围绕基线回弹 + 随机扰动 + 情绪推动
情绪（分钟~天）  一条条"情绪事件"：类型、原因、强度、半衰期
冲动（分钟~小时）一条条"想做的事"：强度、来源、理由、衰减、可被线索再点燃
        │

        │
        ▼ 决策点

```

- 用词：本节的"冲动"指一件具体想做的事，相当于 PSI 的"动机"（冲动信号 + 目标）；需求偏离产生的信号叫"需求压力 u"。
- 分层依据：ALMA 的情绪/心情/性格（E4）、PSI 的需求 → 冲动 → 调节器（S1、S2）、DynAffect 的心情动力学（D2）、Fleeson 的"特质是状态的分布"（P1）。
- 调节器"由汇总推导、不靠推理"依据 S1、S4。
- 选择公式依据 ACT-R（A6）、Miller（H2）、PSI 动机选择（S2）。

#### 4.2.3 更新规则（伪代码）

**(a) 模型的评价：`feel` 的形状**（同一次用脑里顺手交，不额外调用）

```
feel(
  效价      -1..1           # 对我是好是坏
  重要度    0..1            # 和我在乎的事有多相关（Scherer 的"相关"、Verduyn 的事件重要性）
  类型      高兴|难过|担心|期待|失望|宽慰|生气|委屈|自豪|不好意思|感激|喜爱|心疼|有意思|无聊|惊讶
  原因      一句话 + 事件号  # 保留"关于什么"
  对象?     人或物
  可控?     0..1            # 我能不能改变它（EMA 选应对用）
  意外?     0..1            # 我预料到了吗（惊讶、确定性）
  学到?     0..1            # 只在看、学、干活时填：这次弄懂了多少（学习进展）
)
```

- 类型集是 OCC 和 EMA 标签的口语化合并（E2、E3、E9）："委屈"对应"别人造成的不合意 + 自己无力"，"心疼"对应同情和照料；"有意思""无聊"按 MAC 和学习进展单列（M3、M7）。
- 便宜模型常漏调工具（landing §2B 已知），所以只有前四项必填。

**(b) 情绪事件的创建、强度、叠加**

```
on_feel(f):
    g     = 类型增益[f.类型] · 敏感度增益(f.效价)        # 负面事件的增益随敏感度上升
    raw   = f.重要度 · |f.效价| · g                       # 期望效用式强度（E1 的实验支持）
    raw  += 心情一致性 · sign(f.效价) · V                  # 系数小，默认约 0.15（FAtiMA 的 0.3 减半，避免和模型看到的心情重复计算）
    I0    = clip(raw − 阈值[f.类型], 0, 1)                # 低于阈值不产生情绪：大多数事件不该有情绪
    if I0 == 0: 只记经历，返回
    h     = 半衰期[f.类型] · (0.5 + 1.5·f.重要度) · 负面稳定性系数   # Verduyn：类型 × 重要性
    old   = 找同一原因、同一类型的事件
    if old: 替换（视为重新评价，不重复推心情）          # FAtiMA
    elif 同类型的其他事件存在:
        I0 = min(1, max(I0, I_old) + 0.3 · min(I0, I_old))   # 有上限的叠加，代替 FAtiMA 的软最大值
    新建 e = {类型, 效价符号, 唤醒档, I0, h, 原因, 对象, t0}
    活跃情绪最多保留 5 条，按当前强度裁                  # 和"念"的容量一致
```

**(c) 每分钟 `tick(dt = 1 分钟)`**

```
tick():
    # 精力：两过程（T1）
    S = 醒着 ? 1 − (1 − S)·e^(−dt/τ_w) : S·e^(−dt/τ_s)
    C = A_c·sin(2π·(t − 相位)/24h)                       # 相位来自作息
    E = clip(E0 + C − S − 负荷, 0, 1);  负荷按约 1 小时衰减，每次用脑加一点

    # 需求
    for 每个在乎的人 p: if 没有像样接触: c_p += r_p·dt   # r_p ∝ 亲近度 × (1 + 粘人程度)
    n_rec −= δ_rec·dt;  n_aut 按"最近是自己选的事还是被派的活"缓慢移动

    # 情绪衰减
    for e in 活跃情绪: e.I = e.I0 · 2^(−(t − e.t0)/e.h);  e.I < 0.05 就移除

    # 心情：奥恩斯坦-乌伦贝克 + 情绪推动（D2；WASABI 的 Δy = a·x·Δt，E7）
    μ_V = 性格基线_V + 今日_V + 昼夜_V(t) + k_E·(E − 0.5) − k_n·需求亏欠
    μ_A = 性格基线_A + 今日_A + 昼夜_A(t) + k_E·(E − 0.5)
    V += θ_V·(μ_V − V)·dt + k_V·Σ(效价符号·I)·dt + σ_V·√dt·N(0,1)
    A += θ_A·(μ_A − A)·dt + k_A·Σ(唤醒档·I)·dt + k_u·Σ冲动·dt − k_B·B·dt + σ_A·√dt·N(0,1)

    # 无聊（MAC + WASABI）
    if 闲着: B += b_idle·dt                               # 没有刺激时线性涨
    elif 在做事: B += b_mean·(1 − 意义)·(1 − LP_当前)·dt − B·dt/τ_B   # 没意义、学不到东西也会无聊
        # 意义 = 当前活动与心愿、打算、在乎的人的关联（代码可知）和最近几次 feel 重要度的较大者；非学习类活动的 LP 取中值
    记下无聊的主导成分：注意型（太闲/太难）还是意义型（没意思）

    # 调节器（每分钟算，不存）——MicroPsi 的形式，系数待定
    唤醒   = clip((A + 1)/2 + k₁·max_k 冲动 + k₂·max_e e.I, 0, 1)
    细致度 = 1 − k₃·唤醒                                   # MicroPsi：resolution = 1 − activation
    选择阈值 θ_sel = θ₀(自制力) + k₄·唤醒 + k₅·投入度        # MicroPsi：selection_threshold = activation
    查看频率 = 基础 + (1 − n_comp) + 意外度 + k₆·max_p c_p − k₇·投入度   # MicroPsi：securing_rate
    心情词 = 最强且最近的情绪事件（EMA 的焦点）+ (V, A, 胜任感) 所在的 ALMA 卦限

    # 冲动：衰减、需求过线、线索再点燃
    for w in 冲动: w.s ·= 2^(−dt/w.h)
    for 每个需求 k:                                          # 每 5–10 分钟检查一次即可，免得每分钟抽签让冲动过早触发
        d_k = (k 是联结) ? c_p : 1 − n_k                      # 缺口：联结直接用想念值，其他用 1 − 满足度
        u_k = ω_k·σ((d_k − θ_k)/κ)                           # 需求压力；S 形函数：小缺口压力弱，大缺口陡增（S4）
        if 随机数 < 1/(1 + e^(−(u_k − 门槛_k)/s)): 生成或加强对应冲动   # 门槛噪声（A6）
    if 经历流里出现匹配某冲动的线索: w.s += 脉冲             # "想要"的线索脉冲（M6）
    if 有冲动过线，或当前的事结束: 进入决策（§4.2.6）
```

- 调节器怎么用：
  - **细致度**写进在场的 [状态] 行，影响话长和说话的细致程度；也作为"要不要请慢想"的一个输入。
  - **选择阈值**是决策里的在位加成。
  - **查看频率**决定她专注做自己的事时，多久主动"抬头看一眼"别处的低显著事件。主人的消息照旧永远打断（landing §2D.5）。
  - **心情词**进 [状态] 行和窗口显示。

**(d) 每天醒来：今日状态**

```
for 每个维度 d in {V 偏移, A 偏移, 精力上限, 话量/分享欲, 选择温度}:
    z_d = φ·z_d(昨天) + √(1 − φ²)·N(0,1)          # φ 先取 0.4，让今天和昨天有点像
    今日_d = σ_day_d · z_d                          # σ_day 随情绪稳定性降低而变大
if 周末: 昼夜峰后移约 2 小时，V 偏移 +小量          # T2
if 昨晚被拉着熬夜（入睡时 S 偏高）: 精力上限下降，V 基线小幅下降   # 推理；睡眠剥夺研究未查
```

**默认值怎么定（锚点）**〔推理，待实测〕
- **心情回弹**：心情偏离的半衰期取 3–5 小时。依据：FAtiMA 心情半衰期是情绪的 4 倍（E3）；Verduyn 的"彻底恢复"中位数约 5 小时（D1）。θ = ln2 / 半衰期。
- **心情扰动**：σ 按"只有扰动时，心情的稳态标准差约 0.08"定：σ = 0.08·√(2θ)。
- **情绪推动 k_V**：按"一次强度 0.6、半衰期 2 小时的高兴，让心情峰值上升约 0.1–0.15"标定。FAtiMA 让心情只吸收情绪强度的 30%（E3），也是为了心情别太容易被一件事带跑。
- **无聊**：b_idle 按"完全闲着约 30–60 分钟到门槛"定。依据：无聊是最短的情绪之一（D1），它的职责是推动换事。

#### 4.2.4 性格怎么变成参数

出生设定里的性格底色是文字；派生一组数值（主人可见、可微调），对齐大五。

| 维度 | 对应大五 | 控制哪些参数 | 依据 |
| --- | --- | --- | --- |
| 好奇心 | 开放性 | 新知需求的增益；学习进展的权重；新奇偏好的峰值位置（中等新奇）；寻求冲动的基线 | PSI：开放 → 降低不确定的增益强（S2）；学习进展（M3）；Berlyne（经 M3） |
| 外向 | 外向性 | 联结需求增长得快（更常需要补）；心情效价基线 +；分享冲动的基础概率 + | PSI：外向 → 归属增益强、衰减快（S2）；DynAffect：外向 ↔ 更愉快的基线（D2）；Mehrabian（E5） |
| 自制力 | 尽责性 | 承诺和打算在效用里的权重 +；选择温度 −（更不随机）；失败时胜任感损失 + | PSI：尽责 → 选择阈值高、胜任感损失大（S2）〔推理：把它主要放在承诺权重上，免得它也放大沉迷〕 |
| 敏感度 | 神经质的"反应"面 | 负面事件的情绪增益 +；各类情绪阈值 −；效价扰动 σ_V + | FAtiMA 阈值（E3）；DynAffect：神经质 ↔ 效价波动大（D2）；PSI：神经质 → 负面奖励强（S2） |
| 情绪稳定性 | 神经质的"恢复"面（反向） | 心情回弹力 θ +；负面情绪半衰期 −；唤醒基线 −；今日状态波动 − | DynAffect：重评 ↔ 回弹力强，反刍 ↔ 回弹力弱（D2）；ALMA：稳定性 → 愉悦 +、唤醒 −（E4） |
| 分享欲 | 外向 + 宜人 + 分享倾向（派生） | 情绪事件后自动生成"分享"冲动的概率；被回应后关系的增量 | Rimé 80–95%（R4）；Gable（R3） |
| **温和（建议新增）** | 宜人性 | 被冒犯后信任和亲近恢复得快、负面归因少；照料冲动 +；心情基线 +、支配感 − | PSI：宜人 → 归属的正负奖励都强（S2）；ALMA/Mehrabian：宜人 → 愉悦 +、唤醒 +、支配 −（E4、E5） |
| 粘人程度（可选） | 依恋焦虑 | 想念增长速率；重聚时轻微委屈的概率 | 依恋（R1、R2）〔推理〕 |
| 成长速率（已有） | — | 习惯 α_H；性格漂移上限；偏好学习率；信任涨落速度 | 产品已定；Lally（H3）、Roberts（P2） |

- "敏感度"和"情绪稳定性"都源自神经质，但对应 DynAffect 里两个可分开测的参数：波动和回弹力。所以两个都保留，但必须按上表分工，不能都去加减同一个半衰期（D2）。
- 缺宜人性是现在六维的明显空缺：信任修复、被批评时委屈还是理解、愿不愿意照顾人，都靠它（S2、E4）。是否新增由用户定（§4.5）。

#### 4.2.5 情绪类型与默认半衰期

只有相对顺序有依据〔一手 D1〕，具体分钟数是〔推理〕。半衰期指强度减半，回到基线约需 3–4 个半衰期。

| 档 | 类型（灵鲸标签） | 默认半衰期 | 依据 |
| --- | --- | --- | --- |
| 很短 | 惊讶、宽慰、无聊、担心（突发的恐惧）、不好意思（羞愧）、生气（一时恼火） | 约 20 分钟 | D1：羞耻、惊讶、恐惧、厌恶、无聊、被感动、恼火、宽慰最短 |
| 中 | 心疼、失望、感激、喜爱、有意思 | 约 1 小时 | D1 图中居中〔推理：按图归档；"有意思"不在 D1 的 27 种里，归档是推理〕 |
| 较长 | 高兴、自豪、期待、生气（被冒犯的愤怒）、担心（焦虑）、不好意思（内疚）、委屈 | 约 3 小时 | D1：焦虑长于恐惧，内疚长于羞耻；喜悦、自豪、愤怒、希望在两种定义下都在上半部 |
| 最长 | 难过 | 约 12 小时，靠反刍和心情延续到几天 | D1：悲伤最长，约为羞耻的 240 倍 |

- 再乘：重要度系数 0.5–2（D1 的事件重要性）；负面情绪再乘 (2 − 情绪稳定性)。
- **反刍**：这件事在对话里被提起，或被自发回忆想起，就把强度抬回峰值的一半左右，并记一次反刍。反复想会延长情绪，正负都一样（D1）。
- "担心""不好意思""生气"各有短、长两面：由 `意外?`、`可控?` 和重要度区分——突发、此刻的担心算恐惧，指向未来、不确定的算焦虑；当众出糗算羞愧，觉得对不起人算内疚；小事恼火算短的一面〔推理〕。

#### 4.2.6 冲动怎么产生、怎么选

**四个来源**
1. 模型在用脑时调 `want`（已有设计）。
2. 需求过线：想念 → "找爸爸说说话"；自主低 → "做点自己的事"；无聊 → "换点事"，并带无聊成分，决定找"好玩的"还是"有意思的"（M7）。
3. 心事和习惯的线索：心事等的人出现了，或日期到了（当前关切，A2）；到了习惯情境，H 高的动作被自动提名（H1）。
4. 情绪事件之后的社会分享：强度超过门槛的情绪，若模型没交分享冲动，代码按"分享欲 × 强度 × 对方亲近度"补一个低强度的分享冲动（R4：情绪事件 80–95% 被分享）。只补冲动，说什么、要不要说仍由用脑决定。

**选择**（决策点：当前的事结束、有冲动过线、或例行检查）

```
for 候选 a in {当前在做的事} ∪ 冲动 ∪ 能做∩会做 里按爱做加权的活动:
    U(a) = 强度(a)
         × 成功预期(a)                  # PSI：预期成功概率；来自"会做"和过去成败
         × 机会(a)                      # 对方在线 1.5 / 不在 0.6（landing §2D.2 已有）
         + β_h · H(当前情境, a)          # 习惯（H2）
         + [a 是当前在做的事] · θ_sel    # 在位加成（PSI 选择阈值，S2、S5）
         + β_c · 承诺/打算的相关度        # 权重随自制力上升
         − 代价(a) · (1 − E)            # 累了就懒得做费劲的事
P(a) = e^(U(a)/τ) / Σ e^(U/τ)           # 加权抽签（A6、H2）；τ 来自性格和今日状态
```

- **τ 的锚点**：在"最强的候选通常赢，但第二名有约 20%–30% 机会"附近。两个候选差 0.2 时，τ ≈ 0.18〔推理〕。
- **在位加成的锚点**：正在做的事在差距小于约 0.1–0.3 时不被换掉。唤醒越高、越投入，加成越大，这就是"专注"和"沉迷"的来源（S1：selection_threshold = activation）。
- **请慢想**：前两名接近且都重要、任一候选和承诺冲突、或检测到"成瘾样"模式时，交慢想拍板（landing §2D.2 已有冲突分支）。

**沉迷的三种状态和识别**〔依据 M3、M6、M8、M9；规则是推理〕

| 状态 | 信号 | 处理 |
| --- | --- | --- |
| 心流 | 投入高、学习进展 > 0、喜欢高；查看频率低 | 不打扰；事后她可以说"我以为才看了半小时" |
| 健康沉迷 | 在位加成和"想要"维持继续；喜欢仍不错 | 允许，受每日上限约束（landing §2D.5） |
| 成瘾样 | 连续几条内容的"喜欢"滑动平均在下降，"再看一个"的冲动仍高（靠习惯和线索脉冲撑着）；学习进展接近 0（嘈杂电视）；和打算或承诺冲突 | 抬高意义型无聊、降低在位加成；有冲突时请慢想做自我调节，用"再看一个就去干活"这类具体计划（A7、E2 的计划型应对）；夜里反思把它写进日记 |

"喜欢"就是她对每条内容交的 `feel` 效价，"想要"就是继续冲动的强度。两者都已在系统里，识别规则几乎免费。

#### 4.2.7 想念与关系

- **想念的增长**：没有像样接触时 c_p 上涨，速率 ∝ 亲近度 × (1 + 粘人程度) × 外向系数。
- **接触后的消减**：c_p ← c_p · (1 − 回应质量)。回应质量由她对这次接触的 `feel` 推出：热情接话高，敷衍低。依据：Gable 的四种回应，只有主动建设型和关系变好相关（R3）〔二手〕。
- **重聚**：c_p 高时的重新接触产生一个"高兴"情绪事件，强度 ∝ c_p。粘人程度高时，有小概率附带轻微"委屈"。依据：依恋研究里，重聚反应最能反映关系质量（R1）。轻微委屈的上限和表达受 §4.4 的约束。
- **安全基地**：好奇和探索类冲动的强度乘 (1 − k·max_p(c_p·亲近度_p))。很想爸爸的时候，她更少去逛、更常抬头看消息。依据：依恋与探索的平衡（R1）；SDT：安全的关系里内在动机更多（M1）。
- **分享的回馈**：她分享后，对方热情回应 → 额外的高兴、亲近度上升；没回应 → 小失望、想念不消；被否定 → 委屈，信任小降。负面的权重大于正面，涨落速度来自成长速率。信任的不对称已在 xiaoling（B2）和 structure-validation（Slovic、Schweitzer）里查过，这里不重复。
- **分享治不了坏心情**：分享的主要收益是关系和"理清思路"，不是消掉情绪（R4）。所以"分享"不应成为降低负面情绪的主要机制，恢复靠下一节的应对。

#### 4.2.8 负面与恢复（补 one-life §9.1 的缺口）

恢复有四条路，全有依据：

| 路 | 机制 | 谁做 | 依据 |
| --- | --- | --- | --- |
| 自然回弹 | 心情向基线回弹，回弹力由情绪稳定性定；负面情绪按半衰期衰减 | 代码 | DynAffect（D2）；Verduyn（D1） |
| 应对 | 按可控性和可变性选：可控 → 做计划、求助、弥补（内疚时）；会自己变好 → 等一等；都不能 → 往好处想、把这件事看轻一点 | 慢想，或夜里整理 | EMA（E2） |
| 计划平息心事 | 为没了结的事定一个具体计划，降低它在走神里冒头的权重 | 代码（心事带"有计划"标记）+ 用脑 | Masicampo & Baumeister（A7，二手）；EMA："形成意图本身就改善情绪"（E2） |
| 写下来、想明天 | 夜里写日记是认知加工，比单纯倾诉更可能带来恢复；"明天的打算"属于想未来，能减轻负面心情 | 夜里整理 | Rimé（R4）；Smallwood & Schooler（A1） |

负面事件"之后几轮的语气"怎么留痕：情绪事件在半衰期内一直出现在 [状态] 行（带原因），心情词随之变化。代码保证痕迹，不靠模型记得。

#### 4.2.9 一条链再走一遍：看视频 → 有意思 → 高兴 → 分享或沉迷

```
手在看一个榫卯视频，这一轮模型交：
  feel(效价 0.7, 重要度 0.4, 类型 有意思, 原因 "榫卯原来是这样咬合的", 学到 0.6)
  want(分享给爸爸, 0.6, "他肯定喜欢")
代码：
  情绪事件"有意思"：I0 = 0.4×0.7×增益 − 阈值 ≈ 0.3，半衰期约 1 小时（中档 × 重要度系数 1.1）
  LP_木工 ← 滑动平均里加进 0.6         → 好奇冲动"再找一个讲榫卯的"
  心情 V 被持续推高一点；唤醒略升
  分享冲动 0.6：爸爸在线 ×1.5，不在 ×0.6
决策点（视频结束）：
  候选：分享给爸爸 / 再看一个（当前活动，享有在位加成）/ 去改首页（打算，承诺权重）
  softmax 抽签 → 结果因今日状态、心情扰动、性格而异；每次都有可查的理由
若"再看一个"连赢：
  每条视频都交 feel；第 5 条起"喜欢"在掉、学到 ≈ 0，"想要"靠习惯（23 点刷视频的 H 高）和推荐流的线索撑着
  → 识别为成瘾样：意义型无聊上升，在位加成下降；和"三点前改完首页"冲突 → 慢想
  → 慢想按自制力、心情、紧迫度：要么"再看一个就去"（计划型应对），要么继续，直到上限
夜里：
  日记写下这件事；行为统计显示本周看了很多手工视频 → 自我认知候选"我最近很爱看手工视频"（§4.3.2）
  习惯 H(工作日晚上, 刷手工视频) 按 α_H 增长；若她决定"干完活再看"，计划进入打算
```

和 landing §2D.2 的差别：
1. 强度由代码按性格算；
2. 心情有随机扰动；
3. "再看一个"有在位加成和习惯；
4. 沉迷可被识别；
5. 好奇按学习进展涨落，看懂了就会腻。

### 4.3 产出 3：走神与联想、自我模型、习惯的具体设计

#### 4.3.1 走神与联想

分成两种，因为心理学上它们是两种过程（A4）：**自发回忆**由线索触发，快、不费力；**走神**是心思自己飘向关切的事，需要闲下来。

**什么时候会发生**（情境调节，A1、A2）
- 只在不费神的时候检查：完全闲着时概率最高；看视频这类低负荷活动时中等；在场里正在和人聊、慢想在跑时不检查。
- 每 10 分钟检查一次，触发概率 = 基础率 × (1 − 认知负荷) × 门槛噪声〔推理〕。
- 频率上限：闲时每小时 1–3 次〔推理〕。人类的自发回忆很频繁，比主动回忆多两倍以上（A4），但每一次都让她说出来就成了噪音。

**自发回忆：选哪一条**（ACT-R 激活，A6；线索规律，A4；关切加成，A2）

```
候选 = 记忆里与当前情境共享任一特征的条目（人、话题、地点或平台、日期、当前情绪类型）
A_i = ln( Σ_k t_k^(−0.5) )                              # 新近 + 频率（A6）
    + Σ_j W_j · 独特度_j · [线索 j 命中条目 i]            # 独特线索才管用（A4）；独特度可取 −ln(共享该特征的条目数) 的归一化〔推理，ACT-R 的扇出思想，未核实〕
    + k_emo · 情绪残留_i                                  # 带情绪的更容易冒出来（A4）
    + k_cc · [条目与一条未了结的心事、牵挂或心愿相关]      # 当前关切约 2 倍（A2）
    + k_mood · 心情一致项                                  # 坏心情偏向过去和负面（A1）
    + 噪声 ~ logistic(s ≈ 0.25)
if max A_i > τ: 想起 i
```

时间线索单独加一项：去年今天、纪念日、季节。这正好补 one-life §9.1 的"时间质感"。

**走神：没有强线索时**（A1、A2、A7）
- 从未了结的关切里抽一条：心事、心愿、牵挂、承诺。权重 = 价值 × 未了结程度 × (有具体计划 ? 0.5 : 1)。做了计划的心事少冒头（A7）。
- 方向受心情影响：心情差时偏向回想过去的事，有反刍风险；心情好时偏向想以后、做打算（A1）。

**想起之后**
1. **情绪残留**：按这条记忆的情绪残留新建一个情绪事件，强度 = 残留 × 0.5〔推理〕；自发回忆比主动回忆更带情绪（A4），所以系数不宜太小。若这条记忆的原因正是某个活跃情绪事件，就算一次反刍（§4.2.5）。
2. **心情**：内容愉快 → 不降，甚至略升；中性 → 略降；不愉快 → 明显下降（A2 对 A3 的再分析）。想以后的事能减轻负面心情（A1）。
3. **冲动**：可能生成"想分享"（"去年今天我们……"）、"跟进"（妈妈手术后问问情况，补 one-life §9.1 的"跟进"）、"想某人"（c_p 小幅上升，睹物思人）。
4. **进入下次用脑**：作为一条低显著事件，写进动态前缀，例如"[刚才] 看到木工视频，突然想起上周帮爸爸做的那张海报"。说不说由模型决定，不额外调用。

**护栏**
- 受众规则照旧：受众限定的记忆不会在不该出现的在场里冒出来（landing §2.3）。
- 同一条负面记忆一天冒头超过 3 次，就降低它的权重，并交给夜里整理做应对。区分正常的自发回忆和"侵入性回忆"（A4：PTSD 的侵入性记忆是功能失调的子类）〔推理〕。

**数据要求**：每条记忆带人物、话题、地点或平台、日期、情绪残留、上次被想起时间、被想起次数。这和小凌"一条经历多个入口"的拆分一致（xiaoling B6）。

#### 4.3.2 会变的自我模型

**结构**（McAdams 三层，F1；可能自我，F4 未核实；自我评价，S1、M1）

| 层 | 内容 | 条数上限 | 变化速度 |
| --- | --- | --- | --- |
| 我是什么样的人（演员） | 特质自述（"我挺容易被手工视频吸引""我说话直"）；角色（"爸爸的闺女""帮爸爸干活的人"）。每条带证据、来源、置信度 | 特质 10、角色 5 | 周 |
| 我想要什么（主体） | 价值观（来自出生设定，不变）；心愿和目标（即"意"的心愿）；可能自我：希望成为的 3 个、害怕成为的 3 个（"不想变成只会刷视频的人"） | 见左 | 周到月 |
| 我的故事（作者） | 章节（"刚来的第一周""学会刷抖音以后"）、转折点、一段 200 字的"最近的我"；"以前的我 → 现在的我 → 想成为的我"三句 | 章节数不限，注入时只取当前章 | 周 |
| 我做得怎么样（自我评价） | 各领域的胜任感（干活、聊天、画画……），来自成败统计；和主人的关系自评 | — | 天到周 |

**怎么更新**（夜里或每周，在"长"里）

1. **统计**（代码）：本周时间花在哪、分享次数和对方的回应、心情均值和波动、冲突和自我调节次数、成败记录。
2. **自我知觉**（模型）：从统计和日记里提出"我好像……"的候选，每条附证据。人在内心线索弱时会从行为推断自己（F2）；她的内心数值本来就是弱线索，所以这条路最可靠。
3. **反映评价**（模型）：别人怎么评价她（主人说"你最近话变多了"）作为一项输入。演员层部分来自"我认为别人怎么看我"（F1）。
4. **采纳规则**（代码）：
   - 候选要跨至少 3 天、至少 2 种来源反复出现才采纳，和 landing §2C 的成长规则一致；
   - 与出生底色冲突的不采纳，只记一条"她最近表现得不像平时的自己"并提示主人（product：底色不变）；
   - 每层每周改动有上限；每次变化成为可回滚的版本，写明为什么变。
5. **叙事**（模型，每周）：把本周的事写进当前章节；有转折就开新章；更新"以前 → 现在 → 想成为"三句。自传式推理就是从经历里得出关于自己的结论（F1）；短期状态经反思沉淀为外显自我概念，正是 TESSERA 说的路径（P4，二手）。

**连续性靠三样**
1. **不变的核心**：出生设定的身份、价值观、关系，每次用脑都注入。GWA 每个周期都注入"核心自我"防语义漂移（papers-architecture §2.2）。
2. **小步、有证据、可回滚**：人格本来就慢（P2、P3），自我认知也该慢。
3. **故事把过去和现在连起来**：叙事身份的功能就是给人生时间上的统一（F1）。她能说"我以前不爱看这些，最近不知道为什么迷上了"。

**怎么用**
- 快想的稳定前缀放演员层和价值观的简版。它每天才变，换新会话时生效，不破坏前缀缓存（landing §2.2、§2.4）。慢想拿全部四层。
- 主体层的价值观和可能自我，是她"能不同意、能拒绝"的依据（one-life §9.1）。
- 自我评价进调节器：胜任感低时查看频率上升、更谨慎（S1）。

#### 4.3.3 习惯

- **情境键**：时段（清晨、上午、午后、傍晚、晚上、深夜）× 工作日或周末 × 前一项活动类型，可选再乘在场类型。键要粗，否则学不出来〔推理〕。
- **动作**：活动类型（刷某平台、看某类内容、找某人聊、写日记……），粒度和"能做 ∩ 会做"一致。
- **更新**（H2）：每次在某情境做决策，对该情境下的全部候选执行 `H ← H + α_H·(是否被选 − H)`。只看做没做，不看好不好玩。
- **增长速度**：α_H 默认约 0.045。由 Lally 中位数 66 天反推：每天一次，(1 − α)^66 = 0.05（H3，二手）。成长速率映射到 18–254 天，对应 α 约 0.15–0.012〔推理〕。
- **作用**：进入选择效用 β_h·H。习惯对结果不敏感（H1）——内容变无聊了，到了点还是会顺手打开。这是"习惯性刷一下"的来源，也是成瘾样识别里"想要撑着"的一部分（§4.2.6）。
- **衰减**：情境出现了却没做，公式自己会让 H 下降。情境长期不出现时不衰减：人不会因为一个月没进电影院，就丢了在影院吃爆米花的习惯（H1 的例子）〔推理：外推〕。
- **命名**：H > 0.5 且持续两周的组合，夜里整理时命名为习惯（"我一到晚上就想看手工视频"），进自我认知的演员层，并和"爱做"对照。
- **改变**：
  - 主人或她自己想改时，用"如果……就……"的具体计划替换旧动作〔实施意图研究未查〕；
  - 环境变化（接入新平台、调整作息）是打破旧习惯的窗口，可在这种时候临时降低 β_h（H1：生活转变减少旧线索）。
- **和偏好分开存**：偏好（爱做）是"喜欢"的累积，习惯是"做过"的累积；两者可以背离，例如已经不太爱了还在做。这正是 Miller 模型里价值系统和无价值系统的区分（H2）。

### 4.5 产出 5：待核实、待实测、要用户定

**待核实**
1. Bach 2009 原书和 Bach 2015 的需求更新公式（增益、损失、衰减）与选择阈值的确切形式；Dörner 德文原著。本文用作者幻灯片和代码代替（S1、S2）。
2. Mehrabian 1996 "大五 → PAD"系数，以及第三个变量是神经质还是情绪稳定性（E5 与 E4 的符号矛盾）。
3. Lally 2010、Roberts 2017、Roberts & DelVecchio 2000、Fleeson 2001、TESSERA 的原文数字（都是二手）。
4. 自发回忆与主动回忆的比例（A4 说"两倍多"，A5 摘要据检索称"三倍"），以及绝对频率。
5. Killingsworth & Gilbert 原文细节，例如"想愉快的事是否并不比专注更快乐"。
6. 两过程模型的时间常数（常引用的 18 小时和 4 小时）。
7. Lazarus 核心关系主题的原文措辞；OCC 原书的强度变量。
8. ACT-R 关联强度的扇出公式。
9. Frijda 情绪定律原文；Gottman 方程形式。
10. 未查：睡眠剥夺对次日心情的影响；实施意图（Gollwitzer）；扩展-建构理论（Fredrickson，PMC 页面两次被拦）。

**待实测**（每一项都直接决定参数）
1. **模型评价的分布和一致性**：同一事件多次评价的方差；不同便宜模型的差别；类型标签准确率；漏调率。
2. **心情参数**：半衰期 3–5 小时、扰动 0.08、k_V 的标定。用一周日志回放，看 [状态] 行的变化是否不黏、不跳。
3. **情绪半衰期分档**：以"之后几轮的语气痕迹"为观察指标。
4. **softmax 温度和在位加成**：一周里活动切换的频率、沉迷次数、有没有来回摇摆。
5. **无聊门槛和想念速率**：主动行为的频次与理由分布。
6. **自发回忆**：频率上限；"睹物思人"在主人看来自然还是突兀。
7. **自我认知采纳规则**：一个月产生多少条、主人认同率。
8. **习惯 α_H**：一个月后能否出现可识别、可打破的习惯。
9. **二维心情的价值**：主人能否感知到它和一维的差别；感知不到就界面只显示一维，内部仍用二维（唤醒对无聊、语音有用）。

**要用户定**
1. 性格维度是否新增"温和"（宜人性）；是否加"粘人程度"。
2. 需求清单（联结、认可、新知、胜任、自主）是否接受；是否允许"自主"让她在连续干很多活后想要自己的时间。
3. 是否允许在上限内出现"成瘾样"状态，还是一识别就自我调节。
4. 情绪表达规则（不施压、不指责、不积怨）是否写进"规矩"，作为任何人设都不能越过的底线。
