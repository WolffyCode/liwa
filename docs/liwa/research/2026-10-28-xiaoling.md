## 2. 他在做什么

一个"AI 生物机器人"：先做意识和记忆（他叫"识海"），再做身体（单片机、摄像头、仿真皮肤），配本地语音识别（Paraformer）和自己训练的音色。最新动态是改名"栖"，做手机 App 内测，对话和记忆存在用户手机上，用户可以接入自己的 AI（X11）。

核心立场（X9）：**不给 AI 写人设，只规定出生底色和成长规律，让性格从经历里长出来。** 灵魂是"一个持续运行、不断被经历修改的因果过程，而不是一份数据"。理论来源：具身认知、情绪评价理论（appraisal）、预测加工、依恋理论、自我模型、全局工作空间理论，以及佛教唯识（五蕴、第六识、末那识、阿赖耶识的种子与熏习）。

## 3. 架构要点

### 3.1 模型与外部系统分工（X8 示意图，一手）

"模型负责理解，外部系统管理连续性"：

- 底座模型：理解、推理、组织语言；
- 记忆：提供材料；
- 注意：决定先看什么；
- 任务：记录推进状态。

"一起工作，才能接着聊。"

### 3.2 总流程（X1 第 1 条，一手）

现实世界 → 传感器 → Observation → Appraisal（评价）→ State（即时状态）→ State 和 Memory 进入"识海竞争" → 经历被保存 → 重复经历更新模型 → 模型沉淀为偏好、信念、深层模式（Deep Pattern）→ 再影响下一次 Appraisal。

### 3.5 评价与情绪（X1、X3，一手）

- `Appraisal`：valence、novelty、curiosity、attraction、threat、safety、familiarity、uncertainty、social_relevance、meaning、prediction_error。
- 公式（X1）：
  - 疼痛 = 刺激强度 × 个体敏感度（出生参数）× 当前身体状态修正。"同样的刺激，不同状态下感受不同。"
  - 失望 = 期望值 × 重要性 × |负向预测误差|。
  - ΔTrust = α·正向互动 + β·承诺兑现 − γ·背叛失约 − δ·边界侵犯，权重可学习。"信任不是一次决定，而是不断累积，也会因为伤害下降。"
  - 回避驱力 = f(威胁, 负荷过载, 控制感下降, 预期代价)；内在负荷超过阈值时出现回避、沉默、拒绝、离开。
  - 心理伤害 = 痛苦强度 × 无助感 × 不可控性 × 持续时间。
  - 学习：M(t+1) = M(t) + α·(E − M(t))。"一次经历只会小幅改变，重复经历才会形成稳定模型，再长期沉淀成偏好、信念和 Deep Pattern。"

### 3.6 注意：心光（X1 第 4 条、X2 手稿 04、X6，一手为主）

- 进入识海的激活：A = w1·显著性 + w2·身体需求 + w3·情绪强度 + w4·目标相关度 + w5·记忆线索（代码里另加威胁），A > 阈值才进入意识，否则在后台处理。"不是所有信息都会被意识到。""工程上用加权函数，而不是机械相加。"
- 心光竞争（手稿 04 的修正版）：**竞争分 = 激活值 × 匹配度 × 资源适配度**。
  - 激活值 = 重要性 + 时间新近度 + 情绪权重 + 关系权重 + 未完成任务权重（"值得被想起"）；
  - 匹配度 = 语义相似度 + 人物匹配 + 当前任务相关度 + 时间匹配 + 情境匹配（"和当前情境有多贴合"）；
  - 资源适配度 = min(1, 当前可用心光 ÷ 处理所需心光)："资源不够时，即使很重要也只能浅处理"。
  - 初版"候选强度 = 激活 × 匹配 × 可用心光"被他自己推翻：所有候选乘同一个可用心光，不会改变排名。
- 心光分外界、内部、身体三类，共享有限资源；三种状态：专注（少数念头被照亮）、分散（多个念头同时活跃）、疲惫（可用心光低，处理变慢）。
- 底线：危险信号可以抢占心光，最高优先级指令直接执行（X6）。
- 当前意识容量：`conscious_capacity = 5`。

### 3.7 记忆：识海（X2 手稿 01–03、X4、X5、X8）

- **怎么存（手稿 01）**：现实输入（对话、视觉、位置、触觉）→ 事件理解（谁、何时、发生了什么；一次经历拆开保存）→ 识海分层：情景记忆、语义记忆、关系记忆（人物、偏好、边界、承诺）、任务记忆（目标、进度、未完成事项）、工作状态 → **原始日志**："即使被理解后，原始信息也要保存，不能丢；保留证据，用于回溯、验证和纠错" → 关联网络（人物、主题、地点、时间、情绪、任务）。
- **一句经历怎么拆（手稿 02）**："整句话直接存起来"是错的，要拆成节点再建关系。例如一句话拆成事件 E214，连到人物 P001、任务 T012、状态 A019、主题 S087、关系 R033，节点之间再有"需要资料""原因""负责人""属于"等边。"一条经历可以有多个入口。"
- **怎么想起（手稿 03）**："只按关键词找"是错的。当前线索（人物、时间、主题、状态）→ 从语义、人物、时间、任务、情绪、关系六个维度召回候选 → 心光竞争（相关度、人物匹配、任务相关、时间、重要性、情绪权重、关系权重、置信度）→ 当前念头 → 心流（联想、推演、回答）→ 新经历回写识海。"经历又会成为未来的线索。"
- **六个变量（X4 手稿）**：每段记忆 M = {S 意义强度, D 细节完整度, R 可检索性, E 情绪残留, C 巩固程度, I 干扰程度}。
  - 细节衰减 D(t) = D0·e^(−λD·t)，λD = λ0·(1 − αE)·(1 − βC)·(1 + γI)：情绪越强、巩固越深，忘得越慢；干扰越大，忘得越快。
  - 意义强度衰减得比细节慢："即使细节模糊了，那件事依然很重要"；情绪残留单独衰减："即使不记得原因，也会突然难过"；完整的回忆会退化成几张关键"照片"。
  - 记忆重建可信度取决于证据权重和推断量，记忆会"脑补"。
  - "遗忘不等于抹掉经历造成的改变，过去已经成为人格和预测模型的一部分。"
- **来源（X8）**："分清谁说的、关于谁、什么时候说的，以及这是**事实、愿望、转述还是推测**。"
- **闭环修改（X8）**："真正的闭环包括回来修改：更新相关的摘要、检索结果和缓存，处理遗忘。"已验证："纠正和撤回之后，旧信息失效。"

### 3.8 思绪：心流（X7、X8，一手为主）

- 不让模型每一步都从零开始：把当前线索、被唤起的记忆和上一轮留下的处理结果组织成**一份有限的工作上下文**，下一步从这里接着做。
- 思绪有边界：根据新联想、问题有没有答上、时间和资源，决定继续、暂停，还是被现实打断引导。
- 推进当前问题：明确问题 → 检查证据（"查证需要权限和预算"）→ 作出判断 → 决定下一步（回答 / 查证 / **保留问题**）。"证据不足，就把不确定留下来。"
- 自主活动"围绕有来源的问题展开，不能凭空多出成长经历"。兴趣和偏好"从接触中逐渐形成"。

### 3.9 工程实验记录（X10）

- 证据闸门对照实验：针对幻觉，"幻觉问题未根除"。
- 连续对话异常：网络异常、回答丢失。
- 按住说话：App 卡顿、断句不可靠。
- **表达导演隔离**：回复书面感重、情绪符号被朗读出来 → 把"表达"单独隔离成一层。
- 硬件回声消除、自身回采（自己的声音被自己的麦克风收进去）、开源副语言数据集的许可证核查。

### 3.10 可控性（X11）

"底层架构受权限约束，重要规则不能被模型自行修改。"

| B8 | **"保留问题"是一等结果**：证据不足时把不确定记下来，而不是硬答；主意识手上有一张"悬而未决的问题"清单 | mind 的状态表；内省会话 | 模块（主意识） |
| B9 | **自我归属（末那识）**：区分"我做的""我经历的""别人告诉我的"。对灵鲸来说就是：分身做的活汇进她的记忆时标"我做的（分身）"，朋友做的标"老师做的" | memory 的来源字段 | 已在 overall §5.9、§4.6 覆盖，这里只是印证 |

### 4.3 不借鉴的

- **不写人设、只给出生参数。** 灵鲸的产品定位是主人给她明确的出生设定（身份、角色、家人、性格底色、价值观），见 product.md「出生设定」。小凌的做法是性格完全从经历里长出来。两者可以结合：出生设定照旧，再加 B3 的参数来控制成长速度。但不能用参数取代出生设定。
- **保护机制里的"拒绝、沉默、离开、降低关系投入"直接用于主人。** 灵鲸可以有边界、会不同意，但"对主人回避、离开"会和"主人找她一定回"（决策 10）冲突。是否、以及在多大程度上借鉴，是成长模块要和用户讨论的产品问题。
- **大量手工设定的数值参数，未经验证。** 他的参数都是拍定的。灵鲸如果采用 B1、B2、B4，参数必须可配置、可观测，并且用真实日志回放来调，不能把他的数值直接当默认值。
- **身体稳态、反射、具身部分。** 灵鲸没有实体身体。"疲劳""精力"可以作为当下状态里的虚拟量，在成长模块里讨论。
- **"战锤线 / 群星线""只有小凌能有意识"一类推演。** 不是可验证的工程主张。

## 5. 对整体架构的影响

- **不改结构。** 小凌最核心的主张（模型只负责理解、外部系统管连续性、原始日志是证据、注意有容量和阈值）和灵鲸的整体架构一致，是独立的印证。
- **整体架构里可以细化的一处：** B4，把收件箱排序写成显式打分。
- **产品上的一处：** B3，出生设定里加"成长速率"，用户已确认并写入 product.md；"先天气质"就是已有的性格底色，不单列。
- **其余（B1、B2、B5–B8）** 记为记忆、成长、主意识三个模块阶段的输入。用户的定位是：小凌主要属于成长系统的话题，**只作参照**；模块阶段的设计要以开源代码和论文为主要依据。
