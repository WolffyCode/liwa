3 attach：快照与增量共用切点

先订阅并捕获 H，再回放历史；状态必须是 stateAtH。

sequenceDiagram
  participant C as 本机 CLI
  participant H as 宿主流
  participant M as minds 提交观察
  participant L as JSONL
  C->>H: follow(agentId, afterCursor)
  H->>M: 原子安装订阅，取得 H + stateAtH
  H->>L: 读取 (after, H]
  Note over H,M: 读历史期间缓存所有大于 H 的事件
  L-->>H: 已提交历史
  H-->>C: 历史 + H 对应状态
  H-->>C: 按序发送大于 H 的增量
  C->>C: 处理后推进 cursor，重复 seq 去重
  Note over C,H: 缓冲满明确 resync；过期 cursor 明确失败
  C--xH: 断开
  Note over M,L: 任务与持久写入继续

  M->>B: 应用答案

  M->>S: resolved flush + JSON 对齐

5 restart：先停稳，再恢复候选

默认续跑合格的原 running；idle、initializing、归档、无句柄或结果不明不自动运行。

sequenceDiagram
  participant C as 本机 CLI
  participant H as 旧宿主
  participant M as minds / 存储
  participant B as 受管进程
  participant X as 短命替换载体
  participant N as 新宿主
  C->>H: restart(operationId)
  H->>M: 保存 running recovery intent
  H->>H: 停准入并 drain
  H->>B: cancel / 终止范围 / waitForExit
  B-->>H: 确认全范围退出
  H->>M: flush 并关闭持久句柄
  H->>H: 退出，释放内核锁
  X->>N: 经同一 profile 启动
  N->>N: 拿锁，新的 bootId
  N->>M: 严格读 JSON，补日志切点，核对旧进程
  N-->>C: ready 与逐会话恢复状态分开
  N->>M: 合格候选新代 resume + durable 继续输入
  Note over H,X: 未停稳不启动替身；CLI 断开不丢已接受操作

01-brain-host.md §4.2/§5.4；02-minds.md §4.0。〔一手〕paseo-upstream@8018231a:docs/agent-lifecycle.md:17；〔推理〕载体。

6 JSON 与 JSONL：无跨文件事务的提交

单个 JSON 原子写不等于多记录事务；恢复沿同一 operationId 补齐，不重做已确认副作用。

flowchart TB
  I["1 操作 / agent JSON intent durable<br/>稳定 operationId 与 agentId"] --> L["2 JSONL append + flush<br/>opId · gen · 完整事实"]
  L --> J["3 agent JSON checkpoint<br/>recordRevision / appliedLogSeq"]
  J --> A["4 操作回执与 committed 切点<br/>控制事件到此才对外发布"]
  A --> D["5 dispatching intent durable<br/>然后调用 provider"]
  D --> K{"收到明确确认？"}
  K -->|"是"| F["记录 applied / turnId<br/>发布结果"]
  K -->|"否"| U["unknown<br/>停止依赖，核对后再处理"]
  L -.->|"日志在前、JSON 落后"| R["重启按日志补摘要<br/>不重投已发送输入"]
  I -.->|"日志尚未提交"| Q["同 operation 补 admission 或失败<br/>不再分配 agent"]

唯一定义：02-minds.md §2.6。〔一手〕packages/storage/storage-json/README.zh.md:76、packages/storage/storage-domain/README.md:147；〔推理〕提交协议。
