## 2. 每份文档管什么、要定什么

"要定下的东西"是每份文档的交付物：表与字段、接口、算法与参数、出错与恢复、第一版范围。"关键问题"是写之前要研究清楚的事。"依据"列已有调研和还要补的调研。

### 01 agent CLI 接入（brains、procs）：大脑插件

- **管什么**：各家 agent CLI 怎么接进本体，每个提供方一个适配器，就是决策 2、4、7 说的"大脑插件"。统一大脑契约（客户端与会话的接口、事件流、失败类别、用量、续接句柄、能力声明）；Claude Code 适配器（经 Claude Agent SDK 拉起、人设用 preset + append 注入、`settingSources` 隔离、内核工具是原生注入还是 MCP 端点、流式输入与 steer、权限钩子、工具批结束钩子收尾、自动压缩的控制、数据目录、取消）；Codex app-server 适配器（stdio 协议、`developer_instructions`、turn 与 steer、权限、用量、`CODEX_HOME`、原生子 agent 是否继承人设）；通用 ACP 适配器（从 Paseo 上游摘进来，第一版不验收）；每种用脑、每类触发的大脑配置（主用、备用、按触发类别）；备用大脑的离线预审与自动切换；进程监管（先登记再拉起、进程组、握手时限、看门狗、闲置回收、孤儿清理、失败即关闭）；用量归一（token、额度窗口、费用按 token 自算，不信 SDK 估价）；模型差异（DeepSeek 走 Claude Code 外壳、GLM 等备选）；Paseo 可摘代码的清单与许可证处理；**第 0 步大脑探针**（不写本体，用 Claude Code + DeepSeek V4.1 Flash + 8 个在场工具跑 20 个场景，测延迟、漏调回复、选错工具、同批收尾是否可靠、每回合推理次数与成本、身份混淆）。
- **要定下的东西**：大脑契约的 TypeScript 类型；两家适配器的实现要点与差异表；人设注入与工具注入的映射；回合事件的归一格式；失败类别与切换条件；续接与重建的步骤；预审流程与自动指标；进程表与清理规则；用量换算表；探针的场景清单、指标、通过线；从 Paseo 上游摘哪些文件、怎么标注改动。
- **关键问题**：一个回合里能否并行多个工具调用，工具返回后是否必然再推理一次，批结束钩子能不能收尾；Claude Code 外壳跑 DeepSeek 时预设身份会不会和人设打架；新会话能否命中前缀缓存；Codex app-server 当前的 steer、权限钩子、用量字段；CLI 沙箱能否做到"写只限 worktree、读不到数据目录"；本体被杀后 CLI 会不会成孤儿；工具参数能否流式拿到（主控台逐字显示）；订阅制账号的额度窗口怎么读。
- **依据**：`research/2026-10-28-paseo-architecture.md`、`subagent-notes/cli-claude-sdk-codex-app-server.md`、`cli-protocols-acp-a2a-mcp.md`、`cli-paseo-upstream-openclaw-orchestration.md`、`openclaw-architecture.md` §2.2 Q1、Q4、`papers-architecture.md` §3.4、决策 1、2、4、6。**要补的调研**：Claude Agent SDK 最新的钩子、流式输入、`settingSources`、缓存控制、数据目录；Codex app-server 最新协议；并行 tool_use 在各家模型上的行为；Paseo 最新上游的适配器源码与许可证；两家 CLI 的沙箱能力。能实测的直接写小脚本测。
- **第一版**：三个适配器从 Paseo 最新上游一次摘下、套灵鲸契约；Claude V1.0 全验证，Codex V1.0 冒烟后给手用、V1.1 全验证，ACP 摘进来不验收。

### 02 用脑调度（minds、context、toolport、tasks、workspace、outbox）：她怎么用这些大脑

- **管什么**：四种用脑的会话外壳、邮箱（steer、interrupt、抢占、合批）、换新与重建、慢想的优先级与自适应保留；每种用脑的上下文装配（稳定前缀与每轮前缀的层、上限、缓存边界、消融开关、别处简讯、状态行）；内核工具目录（在场 8 个，慢想、手、睡眠各自的）的参数 Schema、校验、会话令牌、按用脑种类与收回过滤、同步执行；请示三路、垫话与回执、待决事项的期限；派活交接包、手上的事的状态机、审核关口、完成核验、worktree 与快照与写租约、她自己的事的手（只读、草稿目录）；对外发言的出口（目标解析、受众检查、家规与限频、出站轻查、出站清洗、投递回执、漏回复兜底、言行回查标记）；主人直连、子会话、叫朋友；换新与换大脑时上下文怎么从经历流重建；20 个场景评测的完整版（在真实本体上重跑探针，含主动开口两种做法的对比）。
- **要定下的东西**：会话表与回合表；邮箱规则表；每种用脑的上下文模板与各层上限；工具目录的 JSON Schema 与错误返回；令牌与过滤；交接包模板；状态机与核验项；outbox 规则 R1–R12 的实现点与目标解析算法；评测场景与指标。
- **关键问题**：便宜模型在 8 个工具下的漏调与选错率（探针给出）；稳定前缀多大能既稳人设又便宜；换新时补多少轮原文；请示垫话的措辞由人设还是固定文案；完成核验能核到什么程度；主动 `say` 的目标在多个端之间怎么选。
- **依据**：`overall.md` §2.4、§4、§5、§8；`structure-validation.md` M1–M16；`papers-architecture.md` §2.4、§3–§4；`companion-architectures.md` §2.2、§3.2、§7；`openclaw-architecture.md` §2.2 Q2、§8。**要补的调研**：很少，主要靠 01 的探针结果。
- **第一版**：全部在 V1.0（她自己的事的手只读；`look`、`consult` 在 V1.1）。

### 03 基础与守护（journal、actions、guard、plugins 最小宿主、配置、备份与迁移）

- **管什么**：经历流的事件信封、流、序号、载荷与大对象；内联与异步投影的运行器、检查点、重建；可删除载荷与级联；副作用协议（先记后做、结果不明、幂等键）；守护（暂停、总闸三档、按触发类别的日预算、家规、能力收回、资源并发、用量记账、平台限频计数）；带版本的配置实体与配置事件；备份（增量、加密）、恢复演练、升级与迁移；插件宿主最小版与账本和引擎的接缝注册。
- **要定下的东西**：事件表、载荷表、大对象目录的结构；每类事件的字段；投影注册与重建的接口；`append` 的乐观并发；`erasePayload` 的级联清单；`admit` 的输入输出与三档的判定；日预算的计数口径（推理次数、token、钱、额度窗口）；配置实体的字段与版本；备份脚本与恢复步骤；node:sqlite 的选型结论。
- **关键问题**：node:sqlite 是否带 FTS5、中文分词怎么办、向量扩展选 sqlite-vec 还是别的；WAL 检查点与监控；单写者在主线程时重查询怎么走 worker；增量备份用 WAL 归档还是按日 `VACUUM INTO`；载荷加密的密钥怎么管；事件 schema 在开发期怎么演进。
- **依据**：`research/2026-10-28-client-backend.md` §3.1–§3.2、`event-log-supplement.md`、`openclaw-architecture.md` §8、`plugin-architecture.md` D1–D3、D7。**要补的调研**：node:sqlite 当前状态与 FTS5、sqlite-vec；TypeScript 下事件溯源的现成做法（Emmett 等）只借思路；SQLite 增量备份实践。
- **第一版**：全部在 V1.0，账本快照和密钥粉碎以后再加。

### 04 生命内核（body、senses、attention、will、scheduler）

- **管什么**：身的全部数值与每分钟一跳（精力两过程、五项需求、情绪事件、两维心情、耐受、今日状态、主导情绪、调节器、不应期、默认评价表、随机源）；感的入站归一、认人、算受众、派生事件；念的优先级枚举、焦点栈、心事（含关注）、注意容量、情境快照、联想与走神的时机；意的账本（承诺、打算、心愿、牵挂、方针、待决事项、决策点记录）、摆桌子、有偏硬币、事实包、沉迷三态【V4】；时钟作业（身的一跳、承诺到期、作息边界、空闲增量、每日、每周、补跑）。
- **要定下的东西**：身的每个量的公式、参数表（初值、来自性格的哪一维、怎么调）、过线的危险率曲线；情绪类型与半衰期分档；心情的回弹与扰动；默认评价表；情境快照的字段；`body.sampled` 的字段；念的优先级表与去向规则；心事的字段与条件匹配；桌子的生成规则与文字化方式；硬币的边界；事实包的字段；作业表与两道闸。
- **关键问题**：便宜模型交感受的分布与漏调率（决定默认表要多大）；参数初值怎么从三份调研里取；L0 模拟器先于本体做，用来调参；不应期和退避的参数；联想候选的打分由记忆模块给，念怎么调用。
- **依据**：`research/2026-10-28-life-psychology.md` §4.2（伪代码与变量表）、`life-games.md` §4.2–§4.3、`life-agents-products.md` §4.2、`structure-validation.md` M1–M3、M8–M11。**要补的调研**：很少；主要靠 L0 模拟器实测。
- **第一版**：V1.0 做精力、联结、心情两维、情绪事件、今日状态、默认评价表、耐受、不应期、心事、承诺、打算、牵挂、待决、决策点、摆桌子、事实包；V1.1 加调节器全五项、注意容量、联想与走神、心愿、硬币。

### 05 记忆系统（memory、people、self 的自我模型、睡眠用脑的记忆部分）

- **管什么**：四类记忆的表与字段、来源与受众、证据事件号；印象摘要；召回（全文、向量、按受众过滤、条数与字数上限）；激活字段与联想候选；空闲增量与每日的记忆提案管线（引擎接缝 ingest、consolidate、rank、forget）；遗忘曲线与"好像"；矛盾版本化；派生记忆的来源链与受众交集；更正、删除、级联；自我模型四层的表、采纳规则、版本与回滚；人物档案（人、账号、候选、合并与拆分、地方、在场者快照、受众计算、地方合并配置、首选地方）；防记忆投毒。
- **要定下的东西**：所有表；召回接口与排序；提案的 JSON Schema 与校验规则；遗忘的参数；印象摘要的生成与更新；自我模型的四层字段与每周改动上限；人物档案的接口；候选账号的证据格式；受众计算的算法。
- **关键问题**：第一版全文检索够不够，向量检索什么时候加、用什么嵌入模型；睡眠用脑一次读多少条、怎么分批；派生记忆怎么防"洗白"来源；自我模型的候选怎么从行为统计里提；人物档案怎么支持 V5 多成员各有账号。
- **依据**：`subagent-notes/memory-papers-core.md`、`memory-oss-source.md`、`memory-benchmarks-poisoning.md`、`papers-architecture.md` §2.3–§2.4、`life-psychology.md` §4.3（自发回忆、自我模型）、`structure-validation.md` M6、M12–M14、决策 20。**要补的调研**：已完成，见 `research/2026-10-28-memory-mechanisms.md`（联想式 / 激活式记忆的源码拆解、巩固与遗忘、自我与人物的先例、Node + SQLite 实测）和 `research/2026-10-28-memory-landscape.md`（GitHub 全景：谁最好、主流怎么做、神经元图谱的位置、检索准确度靠什么）。

### 06 成长系统（self 的出生设定与成长版本、性格参数、作息、skills、日记、睡眠用脑的成长部分）

- **第一版**：V1.0 出生设定、人设三层、成长版本与回滚、性格参数、能的三层最小版（主人教的步骤文本、偏好、习惯计数）、日记；V1.1 干活沉淀的做法、习惯命名、回归题库完整版。

## 5. 怎么研究

每份文档开写前，先按"依据"里的"要补的调研"跑一次调研 agent（一次只跑一个，不开子 agent，产出 `docs/research/2026-10-28-<主题>.md`，格式同已有报告：来源清单、机制对比、对灵鲸的建议、坑、待实测）；读源码优先于读文档；能实测的（CLI 行为、SQLite 特性）直接写小脚本测，结果记进报告。模块文档写完给主人看一页结论和关键取舍，确认后再写下一份。
