A4

四种用脑

在场慢想手睡眠
什么时候这个地方有人说话；有东西要在这里说不对人的冲动过线、几个念头差不多、冲突、请示、异常、心事到期被派活；她自己决定做一件事空闲满条件；夜里
会话每个在场一个，常驻，闲置回收每次新开，处理完保留 5 分钟每件事一个每次作业一个
大脑快而便宜，配备用强Claude / Codex便宜，夜里可换强
能读的记忆本在场受众能知道的全部，外人原文标不可信按发起在场的受众作业范围内
能做的事8 个工具：回复、主动开口、一次内心记录（感受 · 念头 · 事实 · 心事 · 牵挂）、承诺、请示、派活、召回、查看拍板、定方针、定打算、推进心愿、派活、托在场说话、开始或停下一件自己的事、主动开口的判断（第一版）CLI 原生工具（替主人的活限 worktree；她自己的事只有只读工具）、汇报、回问、子会话只有一个 submit，交结构化提案

链路

C1

链路一：主人在 QQ 问"在干嘛"

没有慢想出场；心事由代码注入；妈妈的在场没动；手没停。

sequenceDiagram
  autonumber
  participant O as 爸爸（QQ）
  participant AD as QQ 适配层
  participant S as senses / people
  participant J as 经历流
  participant AT as attention
  participant CX as context
  participant P as 在场用脑（CLI）
  participant TP as toolport / outbox
  O->>AD: 在干嘛
  AD->>S: 标准消息：地方、账号、在场者、说给她的、内容
  S->>J: message.received，来源人 主人，受众 主人
  S->>AT: 事件 + 心事匹配（等爸爸上线）
  AT->>CX: 起在场回合（主人优先，容量有空）
  CX->>P: 稳定前缀（缓存）+ [状态][正在做][心事][记得][刚才想起][别处] + 爸爸说
  P->>TP: 同一批：reply(含感受) · inner(心事已了结)
  TP->>J: effect.intended → effect.completed
  TP->>AD: 投递到那条消息所在的地方
  AD->>O: 回复
  Note over J,AT: 写回：评价进身 · 心事了结 · 用量记账 · 投影更新
C2

链路二：她自己冒出念头（第四版的活动，机制第一版就有）

代码摆桌子，慢想拍板；连续的小选择由硬币；腻和冲突把她拉回决策点。

flowchart TD

  A1 --> TB["意 摆桌子：候选 = 冲动 ∪ 能做∩会做，按爱做加权、按耐受打折<br/>每个候选附身体权重：层级 · 成功预期 · 机会 · 习惯 · 在位加成 − 代价"]
  TB --> SL["慢想（强大脑，新会话）：读心事、承诺、打算、心愿、桌子、摘要<br/>do(看手工视频, 理由)"]

C3

链路三：想找主人（判断归她，边界归你）

代码不发消息、不按阈值放行；它只让想念涨落（含等回音的不应期）、拼事实包、查家规。

flowchart TD
  B["身：对主人的联结涨到 0.7，过线概率命中 → 冲动：想爸爸"] --> HR{"不应期：上次说的话他还没回？<br/>家规：勿扰时段 · 别烦 · 今日条数？"}
  HR -->|命中| HOLD["不起回合；冲动留着，到点再看"]
  HR -->|没设或没命中| FP["意 拼事实包：上次找他 10:00 没回 · 昨晚聊得热 · 现在 14:30 工作日 · 15:00 有会 · 手里有榫卯视频和妈妈的事"]
  FP --> P["判断：第一版默认慢想，评测后可移回在场<br/>前缀 + [想找他] + 事实包 + 教养底线 → 三选一"]
  P -->|说| W["主人的在场按人设措辞 → say"]
  W --> OB["outbox：家规再查一次 → 目标 = 主人最近活动的地方 → 投递 → 记 proactive.sent（理由）"]
  P -->|留成心事| KM["inner(心事)：等他开完会说"]
  P -->|不说| Q["安静结束，冲动按半衰期淡掉"]
  OB --> R["身：想念部分释放，进入等回音的不应期；没回就退避"]
  R --> FB["反馈：回了 / 没回 / 点开没回 / 别烦 → 经历流"]
  FB --> E["当天进心情；夜里进印象（爸爸上班时不爱聊天）和习惯"]
