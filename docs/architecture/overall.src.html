A4

实例会话与四种活

实例会话干活想事（立场 / 出主意）她自己的事整理
数量每个实例 1 个会话（可换代）每件 1 个，可有子会话每件 1 个，每次新开；立场类成员级排队每件 1 个每次作业 1 个，成员级
什么时候路由表把东西送进这个实例：这个人说话；对象是他的冲动、心事、承诺到期；remind 到点；活的汇报、回问、结论；独处实例另管没有对象的身体过线、作息边界归属实例 dispatch实例 ponder实例 do，一律归独处实例空闲满条件；夜里
大脑（任选提供方）快而便宜，配备用；默认底座自带 agentClaude Code / Codex 等强便宜便宜，夜里可换强
能读的记忆本实例受众能知道的（独处：主人可知 + 公开）按归属实例受众召回的 + recall快照 + recall，受众 = 派它的实例的同独处实例全部受众
能做的事reply / no_reply / say、inner、commit、dispatch / ponder、do / manage、remind、answer、recall、look；按实例种类 × 触发消息的发送者角色裁CLI 原生工具（限本 worktree）、ack、report、ask、spawn、inner、recall立场类：decide、pursue、关系与花钱类、dispatch、conclude；出主意类：只读 + conclude只读 + 草稿目录 + inner + report只有 submit
不能做的事改文件、跑命令、上网（只能派活）；定方针、改关系、花钱（只能 ponder）；自报受众对外说话、对人许诺、问主人、直接写账本同左；没有 commit，结论里带「建议承诺」同左；没有 shell任何对外动作
生命周期主人实例常驻；独处按需；别人的实例闲置 1 小时回收（群更短）跟随活结论交回即结束终止条件到，或她停下用完即弃

循环

B1

身的每分钟一跳

确定性：只依赖注入的时钟、带种子的随机和按成员算的情境快照，所以能回放。只有一个身体，所有实例共用。

flowchart TD
  T["每分钟 tick：注入的时钟 + 带种子的随机 + 情境快照"] --> U1["精力：两过程 + 昼夜 + 用脑负荷"]
  U1 --> U2["需求：联结（每个在乎的人）· 认可 · 新知 · 胜任 · 自主"]
  U2 --> U3["情绪事件按类型半衰期衰减；被提起就再点燃"]
  U3 --> U4["心情两维：向基线回弹 + 扰动 + 情绪推动；睡着冻结"]
  U4 --> U5["无聊：闲着涨、做着没意义也涨；有真人的对话没了结就不算闲着<br/>耐受按天回落；冲动衰减、线索再点燃；她选过的冲动按算术消退"]
  U5 --> MOD["调节器（算出来不存）：唤醒 · 细致度 · 专注 · 查看频率 · 心情词"]
  MOD --> TH{"需求过线？<br/>概率随超出程度上升"}
  TH -->|命中| IMP["生成或加强冲动（带来源、带对象）→ 交给念按对象路由"]
  TH -->|没命中| ENDN["结束，几毫秒"]
  IMP --> SAMP["过线 / 档位变化 / 整点：记一条 body.sampled"]
  ENDN -.整点.-> SAMP
