## 1 为什么之前慢、现在怎么提速

之前的节奏是：每份模块文档 = 一轮调研 agent + 一份 600–700 行方案 + 一轮确认，一份约一天；十份就是两周，代码还没动。从现在起改四条：

1. **只有 05 记忆、06 成长做到这个深度**。其余八份写轻量版：只写表、接口、第一版范围、关键算法，150–300 行，不再每份先跑调研；探针或实现里暴露的问题再补。01 与 02、07 与 08 可同时写。
2. **第 0 步大脑探针立刻开工**。它不依赖任何文档，结果反过来定工具契约和在场的默认大脑。
3. **文档和代码交错**：每个里程碑先写"够用"的接口，代码跑起来再回填文档；每个里程碑都有能玩的东西。
4. **调研和实现 agent 并行**（需要主人同意；默认仍一次一个）。
