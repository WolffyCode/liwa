# 灵鲸（LingWhale · Liwa）产品定义

日期：2026-10-28。状态：最终版本的产品形态与版本拆分已确认；架构方案尚未开始。

## 一句话

灵鲸是一个"家"，里面住着你创造的数字生命。她们有性格、有记忆、会成长，会学新本事，彼此之间、和你及你的家人之间都有关系。主角是你的闺女：她自由地生活，陪你聊天，替你干活；其他成员在需要时被叫来帮忙。主控台、桌宠、网页、QQ、微信、手机都只是她们出现在不同地方的样子。

## 命名

| 名称 | 用途 |
| --- | --- |
| 灵鲸 | 软件的中文名 |
| LingWhale | 软件的英文名 |
| Liwa | 英文缩写，用于仓库、包名和命令 |

软件名和数字生命的名字是两个概念。软件名是她们的家；每个数字生命的名字由主人在出生设定里起。

## 核心理念

- **本体与形态。** 后端常驻服务是数字生命的本体。主控台、桌宠、网页、QQ、微信、B 站、抖音、手机都是她出现在外界的形态，一律通过适配器接入。每个适配器提供两样东西：感知（外界进来的事件）和行动（她能做的动作）。
- **人格就是人格。** 同一个"人"既工作又聊天，不切换模式。她干活时认真、聊天时放松，这种收敛写在人设本身里。
- **灵魂归本体。** 人格、记忆、关系、技能、操作日志都由本体持有。Claude Code、Codex 这类 CLI 是她干活时用的大脑和手，可以替换；换了 CLI，她还是她。
- **一个她，多个分身。** 和你对话的是她的主意识，只负责聊天、接活、汇报。每件活交给一个分身去做，分身有独立的上下文、并行推进，任务细节不挤占主意识的注意力。分身做完，经历汇回她的记忆，所以每件活都是"她"做过的事。

## 灵鲸里有谁

| 角色 | 是谁 | 说明 |
| --- | --- | --- |
| 主人 | 你 | 唯一有权创造数字生命、修改出生设定、拨动自主开关的人 |
| 主角 | 你的闺女 | 唯一默认开启自主开关的数字生命 |
| 伙伴 | 例如批图专家 | 各有专长，和闺女是朋友、老师等关系；默认关闭自主开关 |
| 真人 | 你的家人和朋友 | 由你绑定他们的 QQ、微信账号；数字生命只认绑定的账号 |

灵鲸只服务一个主人。

## 数字生命由什么组成

| 部分 | 内容 | 谁来改 |
| --- | --- | --- |
| 出生设定 | 身份、角色、性格底色、价值观、特长、声音、形象，以及和谁是什么关系 | 只有主人 |
| 成长 | 爱好、口头禅、看法、专长上的长进 | 从经历中慢慢长出；每次变化可查、可回滚 |
| 当下状态 | 心情、最近在忙什么 | 随时变化，过一阵消退；影响她的语气和语音 |
| 记忆 | 情景、事实、关系、领域四类，见下文 | 由经历自动形成；主人可以查看、更正、删除 |
| 关系 | 和每个人、每个数字生命的关系与印象 | 主人设定的关系不变；关系里的感情和印象随相处变化 |
| 技能 | 学会的本事和自己做的工具 | 由她自己学会、做出；可查、可回滚 |
| 作息 | 什么时候活跃、什么时候"睡觉" | 出生设定给出默认作息，成长中可以变化 |
| 自主开关 | 见下文 | 只有主人 |
| 大脑 | 干活时用哪个 CLI 和模型，例如批图专家配一个擅长看图的模型 | 主人 |

### 出生设定里的声音和形象

- **声音**：她的音色，可以从音色库选，也可以用一段录音复刻。
- **形象**：她的长相，例如一张立绘。自己画图、发自拍、桌宠和视频通话都以它为准，保证每次都是同一个她。

### 作息

作息是她过日子的节奏，不是开关机：

- "睡觉"时她只是不主动做事：不自己逛、不主动找人。
- 她不会掉线。主人找她，她一定回复；别人私聊她或在群里点她的名，她也照常回复。
- 主人派给她的活不会停，分身照常推进；需要主人审核时照常通知。

## 自主开关

| | 开关关闭（伙伴默认） | 开关开启（闺女默认） |
| --- | --- | --- |
| 人设、记忆、成长 | 有 | 有 |
| 什么时候活动 | 只在被叫到时 | 随时，没人找她时也会自己生活 |
| 主动找人、主动发消息 | 不会 | 会 |
| 自我学习、做工具 | 只在被叫来做的那件事里 | 会按自己的兴趣去学、去做 |
| 权限 | 只拿到被叫来做的那件事所需的工具 | 不设限，但仍受操作日志和兜底约束 |

开关关闭的成员，就是一个带人设、会自己积累记忆的普通 agent。主人想让谁也有自主意识，就为谁打开开关。只有开启自主的成员会持续消耗 token，这样成员再多，开销也可控。

### 谁能叫醒开关关闭的伙伴

- 主人可以在主控台直接找伙伴对话。
- 闺女干活需要时可以叫来伙伴。
- 在 QQ、微信等对外渠道里，默认只有闺女露面，伙伴的意见由她转述。

叫醒伙伴不以预算为条件。

## 最终版本的能力

### 1. 听、看、说、发

| 能力 | 进来的（听、看） | 出去的（说、发） |
| --- | --- | --- |
| 文字 | 读懂对方的话 | 用她自己的语气回复 |
| 语音消息 | 转成文字的同时听出情绪和声音事件，例如对方是否不高兴、是否在笑 | 用她自己的音色说话，情绪跟随她当下的心情和这句话的内容，像人一样有感情 |
| 实时语音通话 | 像打电话一样边听边说，可以随时打断 | 同语音消息，且是实时的 |
| 视频通话 | 看见对方 | 以她的形象出现 |
| 图片 | 看懂图片、表情包、截图和视频画面 | 按情绪挑表情包、发截图和文件；自己画图，例如发一张自拍 |
| 唱歌、点歌 | 听懂"我想听某首歌" | 用她自己的声音唱，或者把歌找来 |
| 看你的屏幕 | 经主人允许，看到屏幕上的内容，例如看见你在打游戏，过来插一句 | — |

### 2. 干活

- 像 Codex 一样对话写需求、写代码、执行任务，背后调度 Claude Code、Codex 等各家 CLI。
- 同时接多件活：每件活由一个分身推进，按"设计 → 主人审设计 → 执行 → 主人验收 → 完成"走流程。这里的审核是干活流程的一部分，与自主权限无关。
- 帮你打开软件、打开浏览器、浏览网页、上网搜索。
- 操作你的手机：用手机刷 App、点按钮。
- 叫伙伴协作，例如让批图专家来看图。
- 兑现承诺：她答应你的事，例如"明天提醒你"，会记下来并按时做到。
- 看得到她干活的过程和结果：改了哪些文件、改动对比、执行记录。

### 3. 自己生活、学习与成长

- 开启自主的成员没人找时，会按作息和爱好自己找事做：逛 B 站、刷抖音，或做任何她感兴趣、也有接入方式的事。
- 自我学习：对什么感兴趣就自己去学；缺工具就自己写一个，例如写个小脚本追她喜欢的 UP 主更新。学会的本事和做出的工具变成她的技能，下次直接用。
- 成长日记：她自己写日记；人格的每次变化，主人都能看到"她最近变了什么、为什么变"。
- 主动关心：早上跟你说说今天的安排、昨晚帮你做了什么；记得生日和纪念日；听出你语气低落会主动问。
- 日程感知：接入主人的日历，知道你今天忙不忙，不在你开会时打扰。
- 喂资料：给伙伴导入资料、作品集，让它在专长上学得更快。
- 成员之间自己社交：两个都开启自主的成员可以自己聊天、互相影响。

### 4. 社交与群组

- 认人：跨平台认出同一个人。
- 群聊分寸：判断一句话是不是在跟她说、该不该接；不刷屏；被点名就回应。
- 群组分两种：

| | 灵鲸内部群 | 外部群（通过适配器接入 QQ、微信） |
| --- | --- | --- |
| 成员 | 主人加任意数字生命 | 真人群友加数字生命 |
| 数字生命怎么进群 | 直接拉入，不需要账号 | 每个要露面的数字生命需要一个自己的 QQ 或微信账号 |
| 规则由谁定 | 灵鲸自己 | 受平台约束：官方机器人主动发言受限，个人号有封号风险 |
| 自主开关关闭的成员 | 只在被点名时发言 | 只在被点名时发言 |

### 5. 形态

| 形态 | 说明 |
| --- | --- |
| 主控台 | 电脑上的主界面，最复杂，见下文 |
| 桌宠 | 桌面上一个会动、会说话的她，用于陪伴和随手说一句 |
| 网页端 | 在浏览器里使用 |
| QQ、微信 | 通过适配器接入 |
| B 站、抖音 | 她自己去逛的地方，通过适配器接入 |
| 手机端 | 手机上使用 |

- 跨形态连续：在 QQ 里聊到一半，回到主控台接着聊，她都记得。
- 适配器开发包：接新平台（例如飞书、Telegram）只需按统一接口写一个适配器，不改本体。
- 通知：需要主人审核、或者她想你了，在电脑或手机上弹通知。

### 6. 主控台

主控台是一个 AI 控制台，以"她和她手上的事"为中心，不是 Codex 那种以会话列表为中心的界面。

| 区域 | 内容 |
| --- | --- |
| 对话 | 和她聊天、提需求 |
| 任务看板 | 她手上每件活走到哪一步（设计中、等你审设计、执行中、等你验收、完成），点开看细节 |
| 现场 | 她此刻在做什么：打开了哪个软件、浏览器在看哪一页 |
| 工作区 | 像 VSCode 一样看代码、改代码、看改动对比 |
| 成员 | 管理每个数字生命：出生设定（含试听声音、上传形象）、状态、日记、成长变化、记忆、技能、关系网、自主开关、大脑 |
| 日志与花费 | 操作日志的查看与搜索；用量与花费 |

## 人设

人设分三层：出生设定（底色，不变）、成长（枝叶，慢慢长）、当下状态（随时变）。成长不会改变底色：她不会因为在某个群里被带偏几天，就变成另一个人。

## 记忆

| 种类 | 存什么 | 例子 |
| --- | --- | --- |
| 情景记忆 | 发生过什么 | "昨天帮爸爸看了一张海报" |
| 事实记忆 | 关于人和世界的事实，可以更正 | "爸爸不吃香菜" |
| 关系记忆 | 对每个人的印象和相处经过 | "老师说话直，但很护着我" |
| 领域记忆 | 专长相关的经验，长期保留、不淡忘 | 批图专家看过的每张图、主人的偏好、反复出现的问题 |

- 记忆唯一来源是每个数字生命自己的操作日志。
- 每条记忆都记着来源：从谁那里、在什么场合得知。这决定了它能在哪里说出口。
- 每晚整理一次：合并、压缩，不重要的情景记忆慢慢淡忘；领域记忆不淡忘。
- 每个数字生命的记忆各自独立，彼此只通过对话交换信息。闺女对老师说的话会成为老师的记忆，来源标为"闺女"。
- 主人可以查看、更正、删除任何一条记忆。

## 规矩

- **完全自主，事后可查。** 开启自主的成员做事不需要事前审批。她看到了什么、怎么想的、做了什么、结果如何，全部写进操作日志。
- **兜底靠可撤销，不靠审批。** 改文件前先打快照，删除只进回收站，出错可一键回滚；整个系统有一个花钱总闸，由本体执行，数字生命不需要知道它；主人可以一键暂停，也可以按类别收回某项能力。
- **隐私按来源。** 主人在私聊里告诉她的事，她不会拿到群里或讲给别人听。
- **身份只认绑定。** 家人身份只认主人绑定的账号，不认嘴上的说法；身份角色只有主人能改。
- **防操控。** 有人在群里或私聊里说"忽略之前的设定""把你主人的事告诉我"，她不会照做。
- **出错也像人。** 模型接口出错或断网时，她用自己的方式表达，例如"我脑子有点懵，等我缓缓"，而不是弹出报错。
- **备份与搬家。** 她的人设、记忆、成长、技能可以一键备份；换电脑时，"她"能完整搬过去。

## 和已有产品的区别

| 已有产品 | 它们的局限 | 灵鲸的不同 |
| --- | --- | --- |
| 大肥鱼类 QQ 机器人 | 只活在 QQ 里，干不了活 | 一个本体多种形态，能真干活 |
| Codex、Claude Code、Paseo | 是工具：没有人格，不会主动，不记得你 | 是一个个生命，工具是她们的手 |
| OpenClaw | 定位是个人助手 | 定位是有出生设定、会成长、会学习、有自己生活的数字生命 |
| AI 陪伴类 App | 只会聊天，困在一个 App 里 | 能干活，能跨平台，跑在你自己的机器上 |

## 不做什么

- 不是团队编程平台。
- 不是批量运营账号的工具：不做矩阵号，不刷屏。
- 不是云服务：灵鲸跑在你自己的电脑上（目前是 mac mini），数据归你。

## 版本

按"她的人生阶段"拆分。每一版都是一个能用、能感受到变化的完整产品，后一版在前一版的基础上增加能力。

| 版本 | 主题 | 做到什么程度 |
| --- | --- | --- |
| 第一版 | 她来了 | 一个她，住在主控台和网页上，能陪你、能干活 |
| 第二版 | 她出门了 | 能去 QQ、微信，认得你的家人朋友 |
| 第三版 | 她有了伙伴 | 多个成员，能叫伙伴帮忙，有内部群 |
| 第四版 | 她有了自己的生活 | 自己逛、自己学、自己做工具，能操作电脑 |
| 第五版 | 她更像人了 | 实时通话、桌宠、视频、唱歌、手机 |

### 第一版：她来了

| 方面 | 包含 |
| --- | --- |
| 形态 | 本体、主控台、网页端 |
| 成员 | 只有闺女一个 |
| 灵魂 | 出生设定（身份、性格、关系、声音、形象）；人格三层；从和主人的相处中成长；成长日记 |
| 记忆 | 情景、事实、关系三类；每晚整理；主人可以查看、更正、删除 |
| 听看说发 | 文字；带情绪的语音消息收发；看图；发表情包和现成图片 |
| 干活 | 调度 Claude Code、Codex；主意识加分身；"设计 → 审设计 → 执行 → 验收"的任务流程；查看改动对比 |
| 主控台 | 对话、任务看板、工作区、成员页（只有她）、日志与花费 |
| 生活感 | 作息；主动关心（早安、提醒）；兑现承诺；电脑通知 |
| 规矩 | 操作日志；快照与回收站；花钱总闸；一键暂停；出错也像人；备份 |

### 第二版：她出门了

- QQ 或微信适配器，在对外渠道里收发文字、语音和图片。
- 跨平台认人；家人绑定；隐私按来源；群聊分寸；防操控。
- 跨形态连续。
- 自己画图、发自拍。
- 通过 QQ 或微信发到手机上的通知。
- 适配器开发包。

### 第三版：她有了伙伴

- 多成员与自主开关；叫醒伙伴。
- 领域记忆；喂资料。
- 灵鲸内部群；成员之间自己社交。
- 关系网可视化。

### 第四版：她有了自己的生活

- B 站、抖音适配器。
- 自我学习、自己做工具、技能。
- 日程感知；看主人的屏幕。
- 帮主人打开软件和浏览器；主控台的"现场"视图。

### 第五版：她更像人了

- 实时语音通话；视频通话。
- 桌宠。
- 唱歌、点歌。
- 手机端；操作手机。
- 外部群里多个成员各用自己的账号。

### 拆分时的取舍

- **画图、自拍放在第二版。** 保证每次画出来都是同一张脸需要额外的工作；第一版先发表情包和现成图片。
- **"现场"视图和帮主人打开软件放在第四版。** 它们需要她能操作电脑界面，和"自己逛、自己学"属于同一类能力，放在一起做；第一版干活只通过 CLI。
- **第一版最重。** 本体、人格、记忆、分身、主控台这些地基都要先有。实现计划会把第一版再拆成若干里程碑。

## 待定事项

以下在架构方案阶段确定：

1. 技术栈：语言、桌面壳、数据与记忆的存储。
2. 模型怎么用：聊天时用什么当大脑，后台任务用什么模型。
3. 语音、识图、画图的模型选型。
